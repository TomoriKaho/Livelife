# 手绘 UI 渲染

公共装饰使用已提交的静态 PNG；底部导航是本轮迁移保留的动态例外。资源来源与重新生成见[静态资源说明](../assets/sketch/README.md)，导航磁盘缓存见[缓存模块](../platform/SKETCH_CACHE.md)。

| 文件 | 职责 |
| --- | --- |
| [static-sketch.ts](static-sketch.ts)、[static-sketch.css](static-sketch.css) | 公共控件的静态纹理、九宫格边框及状态更新 |
| [sketch.js](sketch.js) | v-sketch 生命周期，分别更新公共装饰与导航 |
| [handdrawn.js](handdrawn.js)、[sketch-bitmap.ts](sketch-bitmap.ts) | 仅为底部导航生成合成 PNG，复用内存与磁盘记录 |
| [main.ts](../main.ts) | 配置完成后直接挂载应用，不等待装饰预热或字体完成 |

## 装饰清单与替换范围

| 页面／装饰 | 当前实现 |
| --- | --- |
| 公共页眉、标签、普通按钮、输入框、提示条 | 共享静态轮廓和五种彩铅纹理；无逐控件 PNG 生成 |
| 引导页、详情页、兴趣页 | 静态轮廓、底色及选中态；沿用已有图片与普通图标 |
| 日历面板、筛选、日期选中态 | 九宫格边框与独立纹理；日历标记改为五种静态色点 |
| Agent 可变高度消息、地图搜索与活动卡片 | 九宫格边框适配内容高度，纹理固定尺度平铺 |
| 我的主页与八个子页（资料、兴趣、收藏、账户、密码、通知定位、外观、帮助） | 同一静态装饰路径，无隐藏页面挂载或预热场景 |
| 底部导航 | **动态例外**：黄色底板、选中项挖空与蓝色标签合成为一张 PNG，保留尺寸监听、取消和缓存逻辑 |
| 地图场景、普通 SVG 图标 | 保留原实现；本轮不改地图 Worker、按需绘制和资源释放 |

静态轮廓按 20 CSS px 切角，PNG 为 3 倍分辨率；边段随控件伸缩，填充纸纹单独以 64 CSS px 平铺，避免整张卡片纹理随内容高度拉长。装饰层作为尺寸容器，边框用 `border-image-width` 绘制，不设置实际的 20px 布局边框，避免矮于 40px 的标签被撑大。小控件的边框宽度、底色内缩和圆角按同一比例缩小；需在手机宽度、长文字和不同像素比下检查。文字与点击不依赖装饰图片加载成功；状态更新直接替换装饰属性，不保留上一选中态任务。

本轮保留手绘设计意图，但共享笔迹与纹理代替逐 DOM 位置生成，外观不保证逐像素一致。明显视觉变化仍需成员确认。尚未新增主题切换；资源按 `default` 主题组织，未来主题应提供同一组轮廓、五种填充和色点，导航例外还需同步更新缓存兼容命名空间。

## 启动与排查

已移除 `sketch-warmup.ts`、七页隐藏预热、八个子页准备回调、字体等待和整套缓存恢复。打开应用只加载当前页面使用的静态资源，后续复用浏览器／包内资源缓存。底部导航按需生成或读取自己的 PNG；不承诺首次导航装饰完全没有等待。

`Livelife sketch navigation ready` 输出导航队列的 `generated`、`diskHits`、`memoryHits`、`readMs`、`encodeMs` 与挂载后队列完成时的 `elapsedMs`。它不包含静态资源解码计数，也不能当作地图加载完成时间。旧 `preparation`／`first page` 和整套恢复计数不再输出。

## Android 手绘渲染回归

1. 记录 APK／提交、设备、Android 与 WebView 版本，在 Redmi Note 12 Turbo / Android 15 以及网页分别验证。
2. 清除仅装饰缓存后冷启动，确认无需“准备整套界面”；完全结束进程再启动，比较可交互时间、导航生成／磁盘命中及内存，不以网页数据代替手机结果。
3. 连续滚动日历、我的、Agent，快速往返五个底部入口。确认无闪屏、文字消失、旧导航底色残留；分别打开我的八个子页。
4. 验证 320–430px 手机宽度、横竖屏、1/2/3 倍像素比，以及短按钮、长标题、多行消息、较高卡片：轮廓不裁切、拼接不露缝，纹理不随高度拉长。
5. 切换兴趣筛选、收藏、日历月周视图，确认颜色和白底同步；阻断静态图片请求后内容与点击仍可用。日历不应再包含色点 SVG 滤镜。
6. 验证地图首次加载时抽屉、附近卡片仍可操作，离开地图取消初始化；保留其独立性能测试。

自动检查：`node --test scripts/*.test.mjs`、preview/production 构建。在 Vite 页面 Console 执行 `await (await import('/scripts/static-sketch.browser.mjs')).verifyStaticSketchGeometry()`，实际检查 24–180px 控件的边框绘制框不超出装饰层，且底色与切角比例一致；浏览器缓存检查见[缓存说明](../platform/SKETCH_CACHE.md)。资源体积、启动对比和真机未测项记录在 PR；AI 检查不替代另一名成员的外观与真机验收。
