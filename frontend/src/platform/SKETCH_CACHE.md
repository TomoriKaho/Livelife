# 手绘 PNG 持久化缓存

本文维护 [sketch-cache.ts](sketch-cache.ts) 的存储、兼容与恢复规则；绘制队列和启动日志见[手绘渲染说明](../plugins/README.md)。

## 存储与隔离

Android 和网页通过 [sketch-cache.ts](sketch-cache.ts) 使用 IndexedDB 数据库 `livelife-sketch-cache`，存储仅包含装饰 PNG 与尺寸/访问元数据。Android 数据归属应用内 `https://localhost` 来源；同包名覆盖升级保留兼容缓存，卸载、清除应用存储或系统回收站点缓存后重新生成。网页缓存按协议、主机和端口隔离；同一站点不同预览路径可复用相同装饰，不持久化业务用户数据或凭证。

## 缓存键与兼容

磁盘键是渲染兼容命名空间、设备像素比和完整 SVG（含尺寸、笔触、颜色及选中状态）的 SHA-256。默认命名空间 `pencil-png-v1:rounded-font-v1:default-theme`；改动生成算法、调色板或字体时更新相应版本，主题切换准备新队列时传入对应命名空间，不能仅改变主题名称而继续复用旧队列身份表。应用版本号不直接进入键，兼容升级可以复用。多主题入口的计划在 [#11](https://github.com/TomoriKaho/Livelife/issues/11) 跟进。尺寸变化按新键生成，读取后额外校验 PNG 解码尺寸；损坏记录被删除并重新生成。

## 容量、恢复与降级

磁盘限制为 PNG 内容合计 32 MiB、512 条记录（不含数据库文件和元数据开销）；读写采用异步事务，图片与元数据同时提交。超限时按最近访问顺序淘汰，旧版本/主题与其他无人使用记录一起参与回收。完整预热成功后保存对应尺寸/像素比/兼容版本的准备记录。下一次启动读取完整默认装饰集合，最多并行解码四张 PNG，全部验证成功后一次性装入内存，再显示应用；不会在首次进入各页面时解码默认装饰。兼容缓存跳过隐藏页面预热与重型 SVG 构造，沿用[绘制队列的内存预算](../plugins/README.md#启动预热)。缓存不完整、准备中断或索引不兼容时重新预热；整套加载中发现损坏图片时释放所有候选，不发布半套缓存，再回退准备。字体尚未可用时不记录完整准备成功，避免保存暂时的字体回退布局。数据库 v1 → v2 原子升级并保留旧 PNG，首次迁移需补齐语义别名和准备记录。存储打开或事务超过 1 秒时本次会话禁用磁盘缓存并退回生成；权限、空间、损坏等失败不阻止页面启动。无安全上下文的网页可能不能使用 SHA-256，此时仍可内存缓存与生成。

## 清理与验证

清理只针对这个数据库：网页开发者工具 Application → IndexedDB 中删除 `livelife-sketch-cache`（先关闭该来源的应用页，避免连接阻塞）。Android 成员测试可通过调试 WebView 的开发者工具清理该数据库；系统“清除应用存储”会连同其他应用数据删除，不能作为日常装饰缓存清理。当前没有新增用户可见的清理按钮。

验证步骤见下文；个人页系统返回另见[页面回归](../pages/more/README.md#android-个人页返回回归)。

## 手绘磁盘缓存验证

自动行为测试包含键兼容性和 IndexedDB 不可用降级；真实 IndexedDB 和绘制链路需在浏览器或调试 WebView 验证：

1. 在 frontend/ 执行 `npm run dev`，打开开发地址。等待界面准备完成，在该页面开发者工具 Console 执行：

   ```js
   await (await import('/scripts/sketch-cache.browser.mjs')).verifySketchCache()
   ```

   成功返回检查列表；失败抛出对应原因。此脚本只在开发服务使用，构建产物不包含该脚本。它创建并最终删除独立测试数据库，不清除应用数据库。
2. 检查涵盖连接关闭后 PNG 仍存在、容量按最近访问淘汰、删除、事务中断不产生候选、磁盘命中不编码、损坏 PNG 重建并再次命中、注入存储拒绝/配额错误后仍显示装饰，以及队列销毁后不发布晚到结果。注入配额错误不等于真实磁盘已填满。
3. 单独进行应用启动测试：先清理仅装饰数据库，启动并记录 `Livelife sketch preparation` JSON。完全结束进程后重启，比较 generated/diskHits、累计读取/编码时间和准备总时间。不要只在同一进程切页面，或用内存命中代替磁盘命中。
4. 测试页面尺寸变化、覆盖升级、改变渲染/字体兼容版本和主题命名空间后不会错误复用。Android 完全清除应用存储会删除其他数据，测试时先确认设备上没有需要保留的业务数据。
5. 测量数据库中 metadata 的 size 合计和条目数（PNG 内容默认最多 32 MiB/512 条），记录其与实际数据库物理占用的区别；不把这个数当作原始像素或进程内存。

## 完整缓存恢复回归

1. 查看 preparation 与 first page 日志，确认兼容缓存恢复覆盖全部默认装饰；随后首次进入各页面和“我的”八个子页，默认装饰没有新增解码/编码。仅 generated=0 不足以证明整套恢复。
2. 验证缺失、不兼容或损坏记录会释放全部候选并重新准备；字体尚未完成时不写入完整成功标记。
3. 浏览器、诊断 WebView 与分发 APK 分别记录恢复结果；最新分发 APK 另做真机回归。
