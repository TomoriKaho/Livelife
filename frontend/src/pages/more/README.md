# “我的” · D-07 前端设计

访问 `#/more`。公共页眉与五项 Tab 保留，不再显示开头的“我的”、英文眉题或占位页脚。内容直接从头像、昵称和个人资料开始。页面复用 `../agent/ElasticList.vue`（BetterScroll），提供手指/鼠标拖动的惯性滑动、顶部和底部阻尼回弹、滚轮缓动和键盘滚动；隐藏滚动条，页眉和 Tab 不跟随滚动。回弹 800ms、惯性最长 2500ms，与智能助手列表一致；减少动态效果时关闭惯性和过渡。内容变化由 ResizeObserver 刷新滚动范围；切换面板重建滚动容器并归零，聚焦输入时把控件带入可视区域。

## 首页与交互

定位开关使用设备级持久化偏好，无保存偏好时应用启动会主动请求定位，已有关闭选择继续生效；设置页显示当前定位状态，开启后通过平台请求权限，失败可重试。关闭后停止位置采集和自动附带坐标；切页、重启、登录及账号切换沿用设备选择。系统权限与应用开关分别管理，详见[平台定位](../../platform/README.md#前台定位)。推荐、通知等其他演示设置仍只在本页面生命周期内更新。

登录后以服务端资料为准，空兴趣列表和空简介也是有效保存结果，重新进入页面时不回填演示数据。无会话的界面预览仍使用样例。回归时在独立 Vite 测试标签页进入日历并等待启动完成，在 Console 执行 `await (await import('/scripts/profile.browser.mjs')).verifyEmptyProfile()`；该检查使用虚构资料并恢复原路由与会话存储，不访问真实账号。

1. 个人资料：手绘头像、昵称、校园身份、简介；右上铅笔进入编辑资料。
2. 兴趣小档案：展示已选兴趣，点击“调整”进入选择页。最上方为“个性化推荐”开关，只有启用后才能配置兴趣与方向；关闭时保留已有选择、禁用兴趣按钮与方向卡片，首页显示关闭提示。标签分类复用 `onboarding/options.js`，默认选择体育运动、电影放映、社团活动、学术讲座。兴趣标签之后展示“希望看到什么？”的兴趣优先 / 多些新发现两张卡片，最后保存全部设置。可全部取消标签。删除原推荐设置中的“附近动态”和重复活动提醒；活动提醒只在通知设置出现。
3. 收藏列表：替代原黄色推荐入口，显示总收藏数和待开始数。内部按“待开始 / 进行中 / 已结束”分栏并显示数量；每条活动显示分类、名称、日期、时段、地点，以及“跳转至地图页”“跳转至详情页”和深红色手绘垃圾桶（44×44px 点击区、带活动名的无障碍标签）。移除立即更新数量，栏目为空时提供日历入口，不自动切换栏目。
4. 设置列表：账户与隐私、通知设置、界面风格、帮助与反馈。定位权限位于“账户与隐私”，与推荐数据偏好并列；通知设置包含活动、推荐与免打扰通知，以及提醒时间。

编辑资料中的头像提供三种本地 SVG 示例；“燕园同学”复用智能助手右侧的 `agent/UserPlaneAvatar.vue` 蓝色纸飞机，头像底色使用主题亮黄色彩铅平涂，保留手绘外框，与飞机形成清晰对比。保存后回显到首页，取消不修改原资料。兴趣、个性化推荐开关与推荐方向使用独立草稿，一起保存后回显；返回取消草稿。其他设置和提醒提前时间在当前页面生命周期内立即更新；关闭活动提醒时禁用提前时间选项。

详情面板在 D-07 内切换，没有新增主页面或 Tab。面板栈记录来源，返回时回到先前面板。收藏列表使用 `#/more?pane=favorites`，从地图或详情通过浏览器返回时可直接回到收藏列表。页面切换时归零内容滚动并聚焦标题。浏览器历史管理主路由，面板返回由界面返回按钮管理。

## 视觉与文件分工

- 所有轮廓和彩铅填色使用 `v-sketch`，沿用全局 `sketch.js` 的宽笔触平涂、斜向漏色、轻微圆滑勾线；背景透明，整块组件不倾斜。
- 字体继承小赖字体。昵称 24px，正文设置标题 14–16px，次级说明 11–12px；输入控件 16px，避免手机聚焦时自动放大。
- 黄色为收藏入口与保存按钮的主色；蓝、薄荷、粉、淡紫用于兴趣和设置图标。首页不把所有设置都画成大色块。
- 图标为细线、圆头、自绘 SVG。开关视觉轨道 48×32px，实际按钮 54×44px；减少动态效果时关闭拨动过渡。

## 演示边界与验证

登录用户进入页面时显示资料加载状态，加载成功前禁用「编辑个人资料」与兴趣「调整」，避免把示例值保存到账户。读取失败时保持禁用，使用「重新加载资料」重试；成功后编辑器使用服务端返回的资料与兴趣。读取或保存返回 `401` 时统一清除两种存储中的令牌和当前用户，账户页显示未登录并禁用退出、注销。没有令牌的界面预览仍可编辑本页数据。

在独立 Vite 日历页的 Console 执行 `await (await import('/scripts/profile.browser.mjs')).verifyProfileLoading()` 与 `await (await import('/scripts/profile.browser.mjs')).verifyExpiredProfileSession()`，使用虚构账户和响应验证慢加载、服务/网络失败及重试、GET/PATCH 会话失效后的界面状态；这些检查不访问真实账户，也不代表 Android 真机验收。

个人设置中的推荐、通知偏好仍为演示开关；定位偏好真实控制全应用设备定位，活动查询与账号收藏以对应模块说明为准。账户页显示当前真实登录邮箱和用户 ID；退出登录只撤销当前会话，「注销账号」需输入登录密码二次确认，成功后删除账户、个人资料、兴趣标签、收藏、反馈及其处理记录并清除本地令牌、回到引导页；退出会撤销服务端会话，登录凭证按记住登录状态写入 `localStorage` 或 `sessionStorage`，接口见[客户端账户认证](../../api/README.md#账户认证)。本地存在会话令牌（`livelife.auth.token`，与账户认证共用）时，进入页面读取 `GET /profile/me`，保存资料或兴趣调用 `PATCH /profile/me`（契约见[个人资料 API](../../../../backend/app/api/profile/API.md)）；失败通过页面提示显示，`401` 会清除本地令牌并回到界面预览；没有令牌时不发起资料请求，保存只在本页生效。除定位偏好外的演示设置离开“我的”后恢复示例；收藏使用账号真实数据，行为见下文[账号活动收藏](#账号活动收藏)。密码页只比较两次输入、演示成功状态，输入在完成或卸载时清空，不改变真实账号。反馈使用真实提交与回执，草稿和失败恢复见下文[用户反馈提交与验收](#用户反馈提交与验收)。

独立详情页与地图的楼层/推荐仍有明确标注的演示活动，字符串 ID 不写入账号收藏。真实地图和日历共用收藏组件；收藏中的地图跳转通过本人收藏 UUID 读取当前摘要，选择后端登记建筑，即使活动不在附近时间窗口仍可查看。完整真实详情由 #102 接入，本次收藏列表提供原文入口，不把真实 UUID 交给样例详情页。

`npm run build:preview` 验证测试构建；`npm run test:favorites` 验证确认后更新、失败保留、账号切换隔离、迟到响应和分页。浏览器检查 390px 与 320px 手机布局、滚动回弹、禁用/重新启用兴趣配置、保存与取消、三类列表、空状态、地图楼层定位、详情路由和返回路径。

development / preview 默认启用 `VITE_INTERNAL_TOOLS`，“我的 → 帮助与反馈 → 接口连通性测试”显示当前后端地址和版本，发起真实 hello 请求。请求时显示连接中并禁用重复点击，成功展示 message，失败显示原因并允许重试；超时与响应校验见[请求模块](../../api/README.md#hello-调用与失败处理)。浏览器按加载、成功、后端不可达和重试步骤验证；模拟响应与真实联调分别记录。

production 默认关闭该开关，通过条件动态导入从产物移除组件及 hello 测试请求。正常帮助内容继续保留。模式配置、测试构建与候选构建教程见[前端 README](../../../README.md#内部调试工具与构建模式)。

七个子页面（资料、兴趣、收藏、账户、通知定位、外观、帮助）共用静态装饰资源，不再注册预热步骤或挂载隐藏实例。子页面新增或默认布局改变时，按[手绘回归](../../plugins/README.md#android-手绘渲染回归)检查首次进入、尺寸变化与选中态。

## 用户反馈提交与验收

“我的 → 帮助与反馈 → 想对我们说”需要登录，正文去首尾空白后 1–500 字。页面说明反馈关联账号、保留至注销，并提醒不要填写密码等敏感信息；不会自动附带设备信息、聊天、定位或日志。提交中禁用输入与按钮，服务端确认保存后才清空正文、显示可复制的反馈编号。首期只有提交回执，没有用户反馈历史、处理进度或自动通知；维护者通过[服务器 CLI](../../../../backend/README.md#用户反馈维护)处理，没有管理网页。

失败时在表单内显示原因、保留正文并允许重试。超时不代表服务端没保存，使用同一请求 UUID 重试会返回原回执；编辑正文视为新反馈。草稿与未确认 UUID 仅在当前表单内存，离开帮助面板/页面或刷新会丢失，请先重试确认结果再离开。登录过期、退出或切换账号会清空草稿及回执，旧请求的结果不会返回新账号。

1. 启动配套前后端及独立开发库，用测试账号进入帮助页；空白内容不能提交。填写正文并提交，等待时不能重复操作；成功应显示编号，用维护 `show` 命令确认正文、账户、提交时间和初始 `pending` 状态。
2. 用 DevTools 阻断反馈请求，或停止测试 API，确认不会显示成功，正文保留；恢复网络后重试。模拟服务端已经保存但响应丢失，再重试应取得相同编号、库中只有一条；429 应显示等待提示，5xx 或无效回执仍可重试。
3. 通过 CLI 查看、按状态/时间/账户筛选，并附版本、操作人和原因更新状态；检查处理记录。用旧版本更新应拒绝。普通账号访问反馈列表、详情、状态修改路径不能读取或处理反馈。
4. 账号 A 请求延迟时切换到 B，A 的草稿、回执和错误不能显示；旧 401 不得清除 B 登录。退出/令牌过期显示登录入口。确认注销前反馈仍在，注销后反馈及处理记录均删除，其他账号记录保留。
5. 执行 `npm run test:feedback`、`npm run build:preview` 与 `npm run build:production`。独立 Vite 日历标签页可运行 `await (await import('/scripts/feedback.browser.mjs')).verifyFeedback()`，使用合成账号及替身响应检查页面错误、重试和身份切换；这不代表真实数据库或 Android 验收。

检查 320px、390px 和桌面宽度的长正文、长编号、错误提示、手绘边框及提交按钮内边距；用真实浏览器与开发库核对 CORS、回执和维护结果。网页与 Android 结果分别记录，目标服务器是否迁移部署以真实部署证据为准。

## 前端内部工具开关验收

同一个提交分别验证 preview 和 production，模式选择、环境变量优先级及启动教程见[前端 README](../../../README.md#内部调试工具与构建模式)。

1. `npm run dev`：帮助页显示接口测试；关闭本地开关并重启后隐藏，正常帮助内容可用。
2. `npm run build:preview`、`npm run check:internal-tools -- true`、`npm run preview`：帮助页显示测试工具，真实后端启动后 hello 成功；请求失败仍显示可理解的错误。
3. `npm run build:production`：构建自动确认所有输出 chunk 不含测试组件和 hello 测试代码。刷新预览页，正常帮助内容保留，接口测试入口不出现，访问帮助页也不加载对应异步 chunk。
4. 尝试 `VITE_INTERNAL_TOOLS=true npm run build:production` 和 `VITE_INTERNAL_TOOLS=invalid npm run build:preview`，预期构建拒绝；不要将这种预期失败报告为 CI 异常。
5. 服务器预览仍执行原有运行时配置、不可变资源、许可证及后端 SHA 校验，`check-preview-build.mjs` 同时确认内部测试代码存在。

记录提交 SHA、mode、Node/npm、实际步骤和结果。浏览器模拟响应与真实 API 联调分别记录。production 工具检查通过不等于业务就绪或正式部署完成。

## 账号活动收藏

入口为“我的 → 收藏列表”（`#/more?pane=favorites`）。未登录显示登录入口，不预置演示收藏；登录后读取服务端分页，显示四类计数、空状态、错误重试、重新加载及加载更多。时间分类、未知时间及不可用快照以[后端收藏契约](../../../../backend/app/api/favorites/API.md)为准。列表每分钟及回到前台时重新读取，翻页固定本轮 `as_of`；不保证两个持续打开的设备实时推送同步。

日历活动卡片将收藏操作放在内容下方、右侧对齐，并在卡片四周保留 12px 内边距；长标题和错误提示允许换行，不能挤出卡片。共享收藏按钮保留至少 44px 点击高度，限制在可用宽度内。验收时同时检查未收藏、已收藏、加载、失败及未登录状态的边距。

地图真实活动摘要和日历卡片使用同一个收藏按钮及共享状态。写入成功前保留原状态并禁用重复操作；断网或超时提示重新加载确认，不能把未确认操作显示为保存成功。取消后刷新列表与计数。账号退出、过期或切换立即清空共享内存，身份及请求代次拒绝旧账号、旧分类和写入前的迟到结果。刷新、重新登录及另一登录令牌从服务端恢复。

在独立开发库导入带活动日期/时间的非 demo 信息，登录后按以下步骤联调：

1. 在日历收藏真实活动，进入“我的”查看对应分类，刷新后应保留；查看地图应打开同 UUID 的当前摘要，按钮为已收藏状态。
2. 从地图取消，回到个人列表确认移除；反复点击只产生一次在途写入。演示详情只能显示不支持账号收藏。
3. 保存有起止时间、仅开始时间和仅日期的样本，核对边界及“时间待定”；修改原活动后重新加载使用新字段。清理原记录后仍显示不可用快照，允许取消。
4. 在另一独立浏览器会话使用同账号登录应恢复；切换到另一账号应为空。退出、撤销令牌、延迟响应、断网和重试不得恢复上一账号数据。
