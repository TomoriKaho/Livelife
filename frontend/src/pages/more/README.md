# “我的” · D-07 前端设计

访问 `#/more`。公共页眉与五项 Tab 保留，不再显示开头的“我的”、英文眉题或占位页脚。内容直接从头像、昵称和个人资料开始。页面复用 `../agent/ElasticList.vue`（BetterScroll），提供手指/鼠标拖动的惯性滑动、顶部和底部阻尼回弹、滚轮缓动和键盘滚动；隐藏滚动条，页眉和 Tab 不跟随滚动。回弹 800ms、惯性最长 2500ms，与智能助手列表一致；减少动态效果时关闭惯性和过渡。内容变化由 ResizeObserver 刷新滚动范围；切换面板重建滚动容器并归零，聚焦输入时把控件带入可视区域。

## 首页与交互

1. 个人资料：手绘头像、昵称、校园身份、简介；右上铅笔进入编辑资料。
2. 兴趣小档案：展示已选兴趣，点击“调整”进入选择页。最上方为“个性化推荐”开关，只有启用后才能配置兴趣与方向；关闭时保留已有选择、禁用兴趣按钮与方向卡片，首页显示关闭提示。标签分类复用 `onboarding/options.js`，默认选择体育运动、电影放映、社团活动、学术讲座。兴趣标签之后展示“希望看到什么？”的兴趣优先 / 多些新发现两张卡片，最后保存全部设置。可全部取消标签。删除原推荐设置中的“附近动态”和重复活动提醒；活动提醒只在通知设置出现。
3. 收藏列表：替代原黄色推荐入口，显示总收藏数和待开始数。内部按“待开始 / 进行中 / 已结束”分栏并显示数量；每条活动显示分类、名称、日期、时段、地点，以及“跳转至地图页”“跳转至详情页”和深红色手绘垃圾桶（44×44px 点击区、带活动名的无障碍标签）。移除立即更新数量，栏目为空时提供日历入口，不自动切换栏目。
4. 设置列表：账户与隐私、通知与定位、界面风格、帮助与反馈。

编辑资料中的头像提供三种本地 SVG 示例；“燕园同学”复用智能助手右侧的 `agent/UserPlaneAvatar.vue` 蓝色纸飞机，头像底色使用主题亮黄色彩铅平涂，保留手绘外框，与飞机形成清晰对比。保存后回显到首页，取消不修改原资料。兴趣、个性化推荐开关与推荐方向使用独立草稿，一起保存后回显；返回取消草稿。其他设置和提醒提前时间在当前页面生命周期内立即更新；关闭活动提醒时禁用提前时间选项。

详情面板在 D-07 内切换，没有新增主页面或 Tab。面板栈记录来源：账户 → 修改密码 → 返回，会回到账户。收藏列表使用 `#/more?pane=favorites`，从地图或详情通过浏览器返回时可直接回到收藏列表。页面切换时归零内容滚动并聚焦标题。浏览器历史管理主路由，面板返回由界面返回按钮管理。

## 视觉与文件分工

- 所有轮廓和彩铅填色使用 `v-sketch`，沿用全局 `sketch.js` 的宽笔触平涂、斜向漏色、轻微圆滑勾线；背景透明，整块组件不倾斜。
- 字体继承小赖字体。昵称 24px，正文设置标题 14–16px，次级说明 11–12px；输入控件 16px，避免手机聚焦时自动放大。
- 黄色为收藏入口与保存按钮的主色；蓝、薄荷、粉、淡紫用于兴趣和设置图标。首页不把所有设置都画成大色块。
- 图标为细线、圆头、自绘 SVG。开关视觉轨道 48×32px，实际按钮 54×44px；减少动态效果时关闭拨动过渡。

## 演示边界与验证

账户、设置和活动数据为前端样例；没有账户、推荐、通知、定位或反馈 API 请求，没有调用系统定位/通知权限，也没有 localStorage 持久化。个人设置离开“我的”后恢复示例；收藏状态在日历、地图与“我的”之间共享内存，切换主页面不丢失，刷新后恢复默认收藏。状态按日历固定演示日期的北京时间 `2026-10-03 15:00` 分类，开始时刻算进行中，结束时刻算已结束。密码页只比较两次输入、演示成功状态，输入在完成或卸载时清空，不改变真实账号。退出仅跳回已有登录/引导页面。反馈只展示尚未开放的提示，不发送内容。

活动数据仍硬编码在 `../../data/activities.js`。日历和地图的收藏按钮统一读写 `favorites.js`。地图跳转为 `#/map?activity=<id>`，强制 3D 和全部分类，再展开活动建筑并选中楼层；补充地点建筑 ID 对应本地 OSM 模型，室外地点使用带“地点示意”说明的固定坐标。详情跳转沿用日历的 `#/detail?id=<id>`；详情页展示活动样例，可查看活动内容并返回地图。

`npm run build:preview` 验证测试构建；`npm run test:favorites` 验证时间边界、共享收藏增删与所有活动的详情路由/地图目标。浏览器检查 390px 与 320px 手机布局、滚动回弹、禁用/重新启用兴趣配置、保存与取消、三类列表、空状态、地图楼层定位、详情路由和返回路径。

development / preview 默认启用 `VITE_INTERNAL_TOOLS`，“我的 → 帮助与反馈 → 接口连通性测试”提供真实的 `GET /test/hello` 请求入口。显示当前配置的后端地址，点击后显示连接中状态并禁用重复请求；仅 HTTP 200 且 `message` 为字符串 `hello world` 时展示成功；其他状态、无效 JSON、响应字段不符或网络失败均显示原因并允许重试，10 秒未完成则终止请求并显示超时。后端地址来自 `VITE_API_BASE_URL`，未配置时使用 `http://localhost:8000`。浏览器按加载、成功、后端不可达和重试步骤验证；模拟响应验证需与真实后端联调记录区分。

production 默认关闭该开关，通过条件动态导入从产物移除组件及 hello 测试请求。正常帮助内容继续保留。模式配置、测试构建与候选构建教程见[工程规范](../../../../docs/engineering.md#内部调试工具与构建模式)。

启动准备通过页面注册的预热步骤覆盖八个子页面的默认布局，直接切换隔离实例的显示状态；不会点击保存、请求系统权限或执行接口测试。子页面新增或默认布局改变时同步维护预热清单，再检查首次进入时装饰是否已准备好。
