# LiLi 智能助手 · 前端设计

访问 `http://127.0.0.1:8765/#/agent`。页面沿用公共小赖字体、`v-sketch` 铅笔轮廓与彩铅平涂；公共页眉和底部 Tab 保留，聊天标题、消息滚动区与固定输入区由本页负责。

## 对话与数据

- 页面从后端恢复当前匿名会话；会话消息、来源快照和反馈保存 24 小时。首条历史入口显示当前对话标题和保留期。
- 用户发送问题后通过 SSE 增量显示回答。助手引用展示来源标题、平台/时间、片段和可用的原文链接；资料不足时显示后端提示。
- 从 `mint / blue / pink / lavender / yellow` 五色池稳定分配气泡颜色；公共手绘与静态资源见[手绘渲染](../../plugins/README.md)及[资源说明](../../assets/sketch/README.md)。
- LiLi 原样复用活动日历的定位热气球品牌图标，不添加表情或拟人元素。用户侧使用尖头朝左的浅蓝彩铅纸飞机，由 UserPlaneAvatar.vue 管理。头像由 `LiLiAvatar.vue` 管理，消息/输入区图标由 `AgentIcon.vue` 管理。
- 消息可复制；已完成回答支持点赞/点踩，发送失败可重试。流式未完成的消息刷新后标记为失败，用户可再次提问。
- 第一版不上传图片或文件，输入区不提供附件入口。模型只依据公开信息表，不读取前端页面样例、个人资料或收藏。
- 历史抽屉占手机框架宽度的 2/3，显示当前会话和过期时间；保留遮罩、关闭按钮、Escape 关闭、焦点约束及背景控件隔离。

前端令牌只存于 `sessionStorage`，不写入 URL 或长期存储。密钥只配置在后端；环境需完成 PostgreSQL 迁移和模型配置后才能生成真实回答。页面切换会释放定时器和事件监听。

## 发送与流式更新回归

点击发送按钮或按 Ctrl/Command+Enter 应立即追加一条用户消息并清空草稿；发送期间禁用重复发送。助手文本与来源应在 SSE 到达时逐段显示，无需继续输入或等待整段完成。完成后移除思考提示并显示反馈按钮；失败后可重试，重试不重复追加用户消息。

运行 `npm run dev`，在独立测试标签页进入 `/#/calendar`，等待应用完成启动，然后在开发者工具 Console 执行：

```js
await (await import('/scripts/agent-conversation.browser.mjs')).verifyAgentConversation()
```

该检查在真实页面上临时替换 Agent 会话与 SSE 请求，控制各段到达时机，验证按钮、快捷键、完成、失败及重试行为；不访问真实模型。结束后恢复请求函数、原路由和原 Agent 会话存储。它只用于本地 Vite 开发环境，不代替真实后端联调和移动端键盘验收。

## 布局和动效

正文保留可读的字号与行距；聊天与历史列表统一使用 ElasticList.vue（BetterScroll），提供惯性滚动与顶部、底部的阻尼回弹；不足一屏也允许拖动，松手回到边界，正常阅读位置不会被重置。聊天、附件和历史列表隐藏滚动条；附件单行横向滑动，紧贴输入框上方。较短屏幕仅滚动消息区，输入区位于 Tab 上方。抽屉滑动 380ms，附件菜单轻微上移淡入；思考圆点旋转与省略号交替显示，使用 CSS 动画，支持减少动态效果偏好。

`pageMeta.customHeading` 在 `App.vue` 中省略公共占位标题，`pageMeta.immersive` 省略占位页脚并交由本页管理内容滚动，不影响其他页面的标题和滚动方式。

## 输入与键盘适配

- `ElasticTextarea.vue` 使用原生 textarea 处理输入、光标、选区和中文输入法；外层 BetterScroll 负责纵向触摸滚动及鼠标滚轮。文字区默认一行，字号 16px、行高 24px。上下固定留白共 20px，内部文字滚动区最多 84px（3.5 行），整体最高 104px；留白不随文字滚动，以免在滚动后意外露出完整第四行。按实际排版高度判断，换行输入和自动折行都计入行数；超过 3 行时，输入框右上角出现手绘全屏按钮。
- 展开只把输入区上沿延伸至手机可见区域顶部，下沿保持原来的锚点。附件标签临时隐藏，添加附件与发送按钮保留在底部。右上角切换为取消全屏按钮；收起恢复 3.5 行限制。始终复用同一个 textarea，不销毁或复制输入框，所以草稿、选区与输入焦点得以保留。点击切换按钮阻止 pointerdown 默认失焦，并在点击回调内同步恢复焦点，避免 iOS 的用户手势限制。Escape 可以收起，中文输入法正在组词时不会拦截。
- 输入区始终 Teleport 到 `.phone-shell`，正文通过占位高度预留空间。展开时背景覆盖公共页眉和对话，不会从左右露出下层按钮。
- 键盘适配通过 [VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport) 的 resize/scroll 以及 window resize/scroll 更新；没有该接口时回退到 innerHeight。记录聚焦前的可见高度，聚焦后明显缩小（超过 100px、且没有捏合缩放）时，以 `offsetTop + height` 作为键盘上缘，将输入区底部置于其上方 8px。支持键盘覆盖布局、浏览器同步缩小布局视口，以及聚焦后页面发生平移的情况。无键盘时仍停靠在 Tab 上方；展开与收起不改变此底部规则。失焦后的键盘关闭过程继续跟随可见区域，关闭后恢复原位置。16px 字号同时避免 iOS 聚焦小字输入框时自动放大页面。
- 滚动使用与消息列表相同的惯性和阻尼参数：bounceTime 800ms、swipeTime 2500ms、swipeBounceTime 500ms、滚轮 easeTime 300ms；开启减少动态效果时关闭惯性与过渡。输入后及键盘方向键移动光标后，通过同字体、同宽度的隐藏排版镜像确保当前光标可见；手动滚动阅读时不强制跳回光标。桌面保留原生鼠标选字，不把鼠标拖拽解释为滚动。
- 离开页面时销毁滚动实例、ResizeObserver、视口事件监听与待执行帧。

运行 `npm run test:composer` 验证键盘几何计算与高度边界，`npm run build` 验证 Vue 构建。浏览器缩小视口可模拟键盘压缩；实际 iOS/Android 输入法、中文组词、长按选字与触摸回弹仍应在真机预览中验收。
