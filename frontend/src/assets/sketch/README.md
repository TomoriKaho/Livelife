# 静态手绘装饰

资源位于 `default/`，用于 #44 的首批静态化。`manifest.json` 记录尺寸与 PNG 字节数：6 种轮廓（含五色偏移笔迹）、5 种填充纹理、5 种日历色点，共 16 张。全部为透明 PNG、3 倍分辨率，总压缩大小约 159 KB，全部原始像素合计低于 3 MiB RGBA；不代表浏览器实际总内存。

## 来源与重新生成

轮廓改编自仓库已有 `src/plugins/handdrawn.js` 的采样与复描算法，使用固定种子；纹理由本项目脚本的固定像素噪声和周期笔压生成，没有引入第三方图片或字体。保留仓库原算法的版权／许可要求。离线渲染工具 `@resvg/resvg-js` 使用 MPL-2.0，仅为开发依赖，不进入客户端运行时代码。

在 frontend 目录执行：

```bash
npm ci
npm run sketch:prepare
```

脚本为 [prepare-sketch-assets.mjs](../../../scripts/prepare-sketch-assets.mjs) 与 [sketch-vector.mjs](../../../scripts/sketch-vector.mjs)。普通构建直接使用提交的 PNG，不联网生成、不在设备上转码。修改算法后重新生成 PNG 与清单，并核对差异和测试；不要只手改清单。调整轮廓尺寸需同步 `static-sketch.css` 的切片：源图 288px，切片 60px，对应 20 CSS px。

## 使用约定

卡片边框使用九宫格；纹理独立按固定尺度平铺。不要为每种文本高度或手机尺寸导出一整张高分辨率卡片；图标和文字继续由页面渲染，不烘焙进图片。装饰层不接收点击，图片失败不隐藏内容。

当前只有 `default` 主题；未来按主题目录提供相同资源集合与 CSS 映射，不在本任务新增主题切换。底部导航仍是动态合成例外，详见[装饰清单](../../plugins/README.md#装饰清单与替换范围)。不同宽度、像素比与状态必须完成网页和真机外观验收；当前资源不声称逐像素复现旧笔迹。
