第一次安装怎么做？

  1. 用 Android 手机打开下载页，查看版本信息，点击“下载 APK”。
  2. 按系统提示允许当前浏览器“安装未知应用”，打开下载文件安装“Livelife 测试”。
  3. 已有团队测试包时，安装新版进行覆盖升级；应用不会自动更新，需要重新下载并安装。
  4. 在应用“我的 → 帮助与反馈 → 接口连通性测试”查看版本并测试后端连接。

工程最低支持 Android 7；具体设备兼容性以实际测试为准。iOS 测试分发正在调研，当前没有 iOS 安装包。

入口和版本如何更新？

main 成功构建并部署后，稳定入口切换到新版本；若失败，保留上一成功版本。二维码编码的是稳定页面地址，不绑定某次构建，也没有二维码服务的到期限制。最新版 APK 的信息以下载页为准，页面保持可用仍依赖测试服务器运行。

本页用于团队共享测试。测试某个 PR 时，从该 PR 的自动评论进入它自己的预览和安装包。当前应用包含演示数据，正式版本发布另行安排。
