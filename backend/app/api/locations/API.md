# 地图活动查询 API

地图页从本接口取得北京时间今天至后天尚未结束的活动，前端结合设备定位选出五栋校内具名建筑：有活动的建筑按最早活动开始时间优先，不足五栋时由直线距离最近的无活动建筑补位。接口只读、无需登录，只返回已导入通用信息系统的公开或模拟记录；不接收、保存或上传用户坐标。客户端负责将活动地点原文匹配到建筑 ID，匹配不确定时不显示为附近活动。

## GET /locations/activities

| 查询参数 | 类型与默认值 | 含义 |
| --- | --- | --- |
| `as_of` | 可选，带时区的 ISO 时间；默认服务端当前时刻 | 查询时刻。客户端翻页时沿用首个响应的 `as_of` |
| `limit` | 1–100，默认 100 | 本页原始信息记录数量 |
| `offset` | 非负整数，默认 0 | 按通用信息查询顺序跳过的原始记录数 |

响应 200：

```json
{
  "as_of": "2026-11-11T08:00:00Z",
  "items": [
    {
      "id": "8b4ea069-b7e0-4a15-bcad-2c1ea1a117c0",
      "title": "校园讲座",
      "summary": "活动正文前 300 字",
      "platform": "manual",
      "source_url": "https://example.com/activity",
      "location": "理科教学楼 101",
      "start_at": "2026-11-11T11:00:00Z",
      "end_at": "2026-11-11T13:00:00Z"
    }
  ],
  "next_offset": null
}
```

按北京时间计算 `as_of` 所在日期第三天之后的零点，查询与 `[as_of, 该零点)` 相交的活动，即今天、明天和后天的未结束活动。只有开始时间的活动按时间点处理，已开始且没有结束时间的记录不继续假定正在进行。缺少地点或开始时间的记录不返回。`items` 可能少于 `limit`，因为偏移与页长应用于通用信息记录，随后过滤无地点记录；`next_offset` 非空时继续翻页，不能因 `items` 为空提前结束。顺序沿用通用信息服务的采集时间倒序，客户端按开始时间排列显示。翻页期间信息更新可能令 offset 移动，当前不提供快照游标。

`title`、`source_url`、`end_at` 可为 `null`；`summary` 来自已存正文，不代表自动生成的摘要。默认不缓存响应。无数据库配置返回 503，参数无效返回 422，错误体使用 FastAPI 的 `detail`。服务端调用 [`InformationProvider`](../../services/content/README.md)，不在请求中采集信息或推断地点；真实信源接入仍由对应采集任务完成。
