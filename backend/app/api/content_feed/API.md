# 兴趣广场内容 API

## GET /content/articles

公开、只读，无需登录；直接复用已入库的信息，不需要模型、推荐或画像配置。仅允许导入可公开分发的内容，当前信息表没有逐条可见性字段，不应导入私有信息。

可选查询参数：`keyword`（1–500 字符，标题、正文、来源名称和活动地点的不区分大小写字面子串）、`platform`（小写平台标识，最多 64 字符）、`source_name`（1–500 字符，完整来源名称精确匹配）。文本去除首尾空白，空条件应省略。条件取交集；不支持标签和推荐参数，未知参数返回 422。

`limit` 默认 20，范围 1–50；`offset` 默认 0，非负。按采集时间倒序、UUID 倒序排序。`next_offset` 为下一页偏移或 null。相同采集时间仍有确定顺序；分页期间数据更新可能造成重复或遗漏，客户端按 ID 去重并可刷新。这不是数据库快照游标。

200 示例：

```json
{"items":[{"id":"d071799c-922e-4b8c-b549-778918d60120","title":null,"excerpt":"公开内容正文摘录","platform":"wechat","source_name":null,"source_url":null,"published_at":null,"fetched_at":"2026-11-18T04:00:00Z"}],"next_offset":null}
```

完整类型见 OpenAPI。`id` 为更新保持不变的信息 UUID；`excerpt` 为合并空白后的纯文本正文前 300 字符，截断时追加省略号，不是 AI 摘要。现有采集适配器输出纯文本；摘录层不再解析 HTML 或解码实体，以保留比较表达式、泛型和标签示例等原文。客户端必须按文本显示，不能作为 HTML 注入。空白正文的摘录为空字符串；不返回原始载荷或完整正文。时间为带时区时间。标题、来源名称、链接和发布时间可为 null，不编造缺失值。

客户端分别显示“未提供标题”“来源名称缺失”“暂无正文摘录”“暂无原文链接”和“发布时间未知”。只有 HTTP(S) 原文链接可打开，按纯文本显示所有来源内容，不执行 HTML。响应为 `Cache-Control: no-store`。

参数无效返回 422；数据库未配置返回 503，沿用 `{"detail":"Database is not configured"}`；数据库运行故障为服务端错误，客户端提示重试。空库和无匹配返回 200 空列表，不回退样例。本文接口不提供账号文章收藏、AI 分类或个性化推荐，后续见 #112；无需数据库迁移。
