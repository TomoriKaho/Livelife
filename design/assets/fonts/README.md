# LiveLife 手写字体

- 字体：LXGW WenKai Lite / 霞鹜文楷轻便版，Medium。
- 作者仓库：https://github.com/lxgw/LxgwWenKai-Lite
- 原始文件：https://raw.githubusercontent.com/lxgw/LxgwWenKai-Lite/main/fonts/TTF/LXGWWenKaiLite-Medium.ttf
- 许可：SIL Open Font License 1.1，完整许可证见本目录 `OFL.txt`。
- 使用：通过 `styles.css` 的 `@font-face` 本地加载，中英文统一字族与字重 500，无需安装系统字体。

保留完整轻便版字库，便于之后逐页扩展界面内容。
