# PKU LiveLife · 手机端设计框架

本目录是供开发组参考和复现的静态 UI 原型。页面范围来自 [issue #13](https://github.com/TomoriKaho/Livelife/issues/13)，视觉参考为 `picture_reference/0.png`、`1.png`、`2.png`。

## 打开方式

直接用浏览器打开 `index.html` 即可，无需安装依赖或构建。也可以在仓库根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory design
```

然后访问 `http://127.0.0.1:8765`。电脑端仍然呈现手机布局，最大宽度 430px；窄屏铺满视口。页眉和底部导航固定在框架中，内容区单独滚动，并预留移动设备安全区。

## 视觉基础

- 页面、框架、按钮与卡片底层均为透明，深蓝铅笔线 `--ink: #20304b`。只有勾线、文字和带透明度的彩铅笔触实际着色。
- 对照三张参考图，明黄 `--yellow: #ffdf32` 用于品牌、底部导航；黄色颜料采用更饱和的亮黄色阶并略加重着色，保留纸齿和斜向漏色。浅蓝 `--blue: #9ac8f2` 用于当前导航。
- 薄荷绿 `--mint: #c4eed7`、粉红 `--pink: #fac4ba`、淡紫 `--lavender: #d9c8f3` 是辅助填色。
- 页眉品牌占比、较大的深蓝图标、轻微黄色偏移笔迹和底部导航层级向参考图靠拢。主导航仅当前项显示浅蓝勾线框，其余项保留图标与文字；模块数量、顺序、页面占位和跳转均不变。
- 底部 Tab 栏仅上沿有手绘勾线，左上、右上为圆角，中间保持平直；黄色彩铅色面在左、右、下三侧铺满手机框架，不绘制侧边或底边，也不留内缩空隙。当前 Tab 的浅蓝小框仍完整勾线。
- `sketch.js` 在控件的真实像素尺寸中逐点采样带圆角的手绘轮廓，以二次贝塞尔曲线平滑插值，叠加轻微弯曲、小幅抖动、偏移复描和深浅不同的局部勾线。圆角由 SVG 勾线呈现，按钮背景保持透明，不使用 CSS 圆角背景色块。按钮、卡片及品牌整体水平摆放。
- 通过 `data-pencil="yellow|blue|mint|pink|lavender"` 指定彩铅配色。底面透明，浅颜料层与 12–18px 宽的轻压笔触沿 -30° 方向密集叠涂。浓淡变化沿笔触展开，漏色集中在同向笔触的相接处，呈细长、两端渐细的断续缺口，模拟斜向平涂；所有颜料经过纸齿透明度滤镜，不叠加白色或纸色底层。
- 每个控件的随机种子固定，切换页面不会令同一控件的笔迹闪动；`ResizeObserver` 在控件尺寸变化后重新绘制。装饰 SVG 不接收点击，也不进入无障碍树。
- 中英文统一使用本地 [霞鹜文楷轻便版](https://github.com/lxgw/LxgwWenKai-Lite) Medium，字重 500；品牌、标题与导航用轻微文字描边增强层级，未加载时回退至楷体。字体文件与 SIL OFL 1.1 许可证一并存放于 `assets/fonts/`，离线也可查看。

## 文件与后续扩展

- `index.html`：公共结构及本地 SVG 图标。
- `styles.css`：配色变量、手绘样式、固定手机框架、弹窗及窄屏适配。
- `sketch.js`：可复用手绘轮廓与彩铅涂抹渲染器，`HandDrawn.refresh()` 可为后续新增控件接入样式。
- `app.js`：`pages` 页面清单、哈希导航与公共框架更新。
- `assets/fonts/`：中文与英文共用的手写字体及许可证。
- `assets/pencil-grain.svg`：备用轻纸纹资源；当前透明背景不使用该资源。

下一步逐页实现 `#page-outlet` 内的内容，保留共享的页眉、标题栏与底部导航。迁移到 Vue 时可将公共结构拆分为 `AppShell`、`AppHeader`、`PageHeading`、`BottomNav` 和 `PageDirectory`，将 `pages` 对应为路由元数据；业务页面替换为路由视图。
