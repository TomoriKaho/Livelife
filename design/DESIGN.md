# PKU LiveLife · 手机端统一设计规范

本目录是供开发组参考和复现的 Vue 3 手机端 UI 原型，采用 Vite、Vue Router 与独立 `.vue` 页面。页面范围来自 [issue #13](https://github.com/TomoriKaho/Livelife/issues/13)，视觉参考为 `picture_reference/0.png`、`1.png`、`2.png`。

本文记录截至 2026-10-03 经多轮调整确认的公共视觉基线，供后续页面设计、组件扩展及开发复现使用。参数以当前 `styles.css`、`sketch.js` 为准；后续修改公共样式时同步更新本文件。业务模块与页面数量由 issue 决定，参考图用于确定视觉语言，不直接照搬其中的业务内容。

## 打开方式

在仓库根目录运行以下命令（Node.js `^20.19.0 || >=22.12.0`）：

```powershell
cd design
npm ci
npm run dev
```

然后访问 `http://127.0.0.1:8765`。电脑端仍然呈现手机布局，最大宽度 430px；窄屏铺满视口。页眉和底部导航固定在框架中，内容区单独滚动，并预留移动设备安全区。

开发源文件需要通过 Vite 预览，不能再直接双击 `index.html` 或用 Python 服务原始目录。`npm run build` 生成 `dist/`，`npm run preview` 在 8766 端口预览构建结果。构建产物也可通过静态服务器提供：`python -m http.server 8766 --bind 127.0.0.1 --directory dist`。字体、脚本及样式均本地打包，字体许可证随构建输出。

`index.html` 是 Vue 的单一挂载入口；各界面的实际内容已分在 `src/pages/` 的七个文件里。团队并行工作应修改所负责页面的 `.vue` 文件，不需要复制入口 HTML 或重复维护公共页眉、Tab。

## 1. 视觉语言与统一原则

整体方向是明亮、轻松、圆润的校园手绘界面。深蓝铅笔勾线确定轮廓，明黄建立品牌与导航识别，浅蓝表示当前选择；薄荷绿、粉红、淡紫提供辅助层级。字形柔和，色面有笔触与浓淡，布局本身保持整齐。

以下规则是已经确认的公共基线：

1. **轮廓轻微不规则，但平滑克制。** 保留手画时的小幅起伏和复描，不能出现明显锯齿、剧烈抖动或夸张扭曲。
2. **勾线保留圆角，CSS 底面保持透明。** 圆角属于 SVG 轮廓及其填色裁剪形状，不用一个实心 CSS 圆角矩形垫在下面。此前“去掉背景圆角”的要求不表示把勾线改成直角。
3. **彩铅采用宽笔触、密集平涂。** 先形成连续色面，再表现沿同一方向的浓淡和少量漏色。避免细线排线、稀疏斜线、随机大面积白洞或完全均匀的纯色。
4. **漏色跟随斜向涂抹。** 使用细长、渐尖、断续的斜向缺口，不用无方向的散点或云状斑块。
5. **黄色明亮、饱和。** 保留纸齿和深浅变化，但整体不能变成灰黄、土黄或过浅的奶油色。
6. **组件整体水平摆放。** 品牌、按钮、卡片不做整体旋转。少量装饰短线、星芒可以有局部角度，不能带动内容倾斜。
7. **中英文统一采用圆润手写字体。** 当前使用小赖字体；正文、标题、按钮、导航均继承同一字族，不混入楷体、黑体或棱角突出的展示字体。
8. **内容与轮廓之间留出空间。** 图标和文字应比按钮小一圈；增加触控区域时优先扩大容器，不同步放大里面的内容。

参考图的作用是校准明黄、浅蓝、深蓝线条、品牌比例和导航层级。当前页面中的占位框与占位说明是设计审阅设施，后续业务内容不必复制这些占位装饰。

### 2.3 透明背景的准确含义

`:root`、`body`、`.phone-shell`、按钮、卡片的 CSS 底层使用 `background: transparent`。彩铅颜料本身仍有颜色和透明度；其上叠加纸齿滤镜和漏色蒙版。透明并不意味着删掉黄色或蓝色填色。

浏览器默认画布可能显示为白色，这不是原型绘制的白色背景。除 D-01 外，不要为了“纸感”重新添加整页纸色、白色卡片底或纹理底图。D-01 引导页使用浅米白 `#f8f4ea` 纯色底，没有点阵或纹理。没有彩铅填色的引导卡片使用 `#fff` 白底，并裁在同一条铅笔勾线内。`assets/pencil-grain.svg` 当前不参与绘制。

## 4. 铅笔勾线与边缘绘制

### 4.1 通用按钮、卡片轮廓

统一复用 `sketch.js` 的 `perimeter()` 与 `pathFor()`。轮廓按元素真实的 `clientWidth`、`clientHeight` 绘制，流程为：圆角矩形采样 → 小幅坐标偏移 → 二次贝塞尔平滑 → 主线、复描、局部压力叠加。

| 参数 | 当前实现 |
| --- | --- |
| 轮廓内缩 | 4px，给线宽与轻微偏移留余量 |
| 圆角半径 | `min(15, height / 3, width / 4)`，单位 px |
| 圆角采样 | 每个四分之一圆弧分成 9 段，含端点 10 个采样点 |
| 直边采样 | 约每 5px 一个点 |
| x 方向起伏 | `sin(i × .34 + seed) × .6 + (rng − .5) × .45` |
| y 方向起伏 | `sin(i × .27 + seed × .7) × .55 + (rng − .5) × .4` |
| 复描偏移 | 第二遍 x 增加 .2px、y 减少 .16px，并使用不同的固定随机序列 |
| 平滑方式 | 相邻点取中点，使用连续二次贝塞尔 `Q` 连接 |

坐标起伏量级在约 1px 以内，平滑后更克制。不能随组件尺寸等比例放大抖动，也不能把采样点用粗折线直接连接。圆角轮廓与彩铅裁剪共用同一条路径，色面形状与勾线一致。

### 4.2 线条层次

| 层 | 线宽 | 不透明度 | 用途 |
| --- | --- | --- | --- |
| 主勾线 | 1.65px | .92 | 深蓝主体轮廓，圆滑转角 |
| 偏移复描 | .65px | .54 | 模拟铅笔轻微重复描画 |
| 局部短勾线 | .6–1.5px | .2–.75 | 模拟局部压力变化，圆头短线 |
| 当前占位区主线 | .85px | .4 | 低存在感的大占位框，颜色 `#7f91a3` |
| 当前占位区复描 | .65px | .24 | 与占位主线配合；不叠加局部重线 |

主线和复描采用圆滑连接，局部短线使用圆头。局部加深应断续、轻量，不能让整圈轮廓都变成两条明显平行线或厚重黑边。弱占位框的参数是当前占位专用，业务卡片默认采用通用轮廓。

部分组件保留彩铅偏移笔迹：品牌、占位纸片与选中 Tab，沿轮廓采样点的前约 58% 画一条 3.6px、透明度 .72 的短色线，偏移 `(2px, 3px)`。占位纸片偏蓝，其他偏黄。D-01 的登录/注册切换、性别与兴趣标签、授权按钮使用 `sketch-cast`。切换为白底浅蓝偏移。性别与兴趣标签未选中时仍是白底，阴影颜色与该标签的彩铅一致；选中后填色与阴影同色。授权按钮白底为浅蓝，已允许为黄。这是有限范围的辅助笔迹，不是实心阴影，也不默认应用到所有业务卡片。

### 4.3 Tab 栏的特殊边缘

整条 Tab 栏不能套用通用闭合四边框，必须使用 `topEdge()`：

- **只有上沿勾线。** 左、右、下不画长侧边或底边，黄色色面直接贴住手机框架。
- **左上、右上有圆角。** 半径为 `min(14, width / 8)`；两端圆弧将上沿自然接到左右边缘。圆弧属于上沿，不继续向下画侧边。
- **中间总体平直。** 不加入中心下凹、拱起或波浪；仅保留细微手绘起伏。
- 上沿基准为 SVG 内 y=2.5px；第二遍复描上移 .16px。直段扰动为 `sin(πi / steps) × [sin(i × .3 + seed) × .35 + (rng − .5) × .3]`，让起伏在两端衰减。
- 填色裁剪路径沿上沿走完，再连接右下、左下闭合；**裁剪闭合不代表勾线闭合**。勾线路径始终开放。
- 当前选中 Tab 的浅蓝小框仍采用通用圆角闭合轮廓，与整条黄色导航带的开放上沿区分开。

“两端有一点向下的弯曲”指左上、右上圆角，不指整条上沿中间向下弯。

## 5. 彩铅纹理绘制方法

### 5.1 期望观感与合成顺序

目标是斜向、宽笔触的彩铅平涂：远看色面连续，近看有交叠、深浅和少量同向漏色。浓淡变化占主导，缺失颜料只是细节。

当前 SVG 合成顺序如下：

1. 使用勾线轮廓建立 `clipPath`，限制颜料范围。
2. 画带透明度的浅颜料层，使用该色阶的第三个颜色。
3. 叠加两遍同向的宽笔触，颜色与笔压变化形成深浅。
4. 对整组颜料应用纸齿透明度滤镜。
5. 应用与笔触同方向的渐尖缺口蒙版，少量去除颜料。
6. 将色面裁剪到轮廓内部；选中 Tab 另有区域蒙版，避免黄色与蓝色混色。
7. 在颜料上绘制辅助色笔迹、主勾线、复描和局部石墨线。

浅颜料层也经过滤镜和蒙版，不是放在纹理下的不透明底板。蒙版里的黑白只控制透明度，不会作为黑白色块画到页面上。

### 5.2 同向宽笔触

颜料和漏色共用 `pencilSpace()` 中 **−30°** 的旋转坐标。在屏幕上表现为由左下向右上延伸的斜向平涂。通过 `along`（顺着笔触）、`across`（跨越笔触）两个坐标生成纹理，不为不同组件随意改变方向。

| 参数 | 当前值 | 视觉作用 |
| --- | --- | --- |
| 浅颜料层透明度 | 黄色 .72，其他 .54 | 黄色更明亮饱和，其他保持柔和 |
| 平涂遍数 | 2 遍，第二遍横向笔触坐标起点偏移 2px | 密集交叠形成连续色面 |
| 笔触行距 | 4.5–5.3px | 行距明显小于笔触宽度，避免稀疏排线 |
| 笔触宽度 | 12–18px，圆头 | 体现较粗彩铅平涂 |
| 单段长度 | 30–85px | 打散机械的整条条纹 |
| 相邻段交叠 | 8px | 色面衔接，减少突兀断口 |
| 每段采样 | 5 段、6 个点，贝塞尔平滑 | 笔触轻微自然起伏 |
| 跨笔触方向摆动 | `sin(along / 22 + seed) × 1.3 + (rng − .5) × .6` | 轻微不齐，仍保持整体方向 |
| 笔触基础透明度 | .11–.23，再乘笔压 | 通过交叠产生浓淡，不靠纯色块 |

笔压计算为：

```text
pressure = .72
         + .23 × sin(center / 48 + row / 17 + seed)
         + .17 × sin(center / 87 − row / 29)
opacity  = (.11 + random × .12) × pressure
```

其中 `center` 是当前笔触段的中心，`row` 是跨笔触坐标。变化沿笔触展开，而不是每个像素都随意换深浅。增加密度时优先调整交叠、颜料透明度或纸齿覆盖，不把笔触变回细线，也不取消浓淡差异。

### 5.3 纸齿透明度滤镜

纸齿模拟颜料在细小纸纹上的附着差异，只用于细尺度质感：

- `feTurbulence`：`type="fractalNoise"`，`baseFrequency=".85"`，`numOctaves="3"`，固定种子。
- `feColorMatrix`：颜色通道不用于输出色彩，将噪声 RGB 按 `.28 / .53 / .19` 加权转成 alpha。
- `feComponentTransfer`：alpha 线性映射，`slope=2.6`；黄色 `intercept=−.38`，其他 `−.5`。黄色覆盖更实，避免被透明度冲淡。
- `feComposite`：`SourceGraphic in paperCoverage`，保留颜料原色，按纸齿覆盖度改变透明度。
- 滤镜采用 `sRGB`，范围与组件尺寸一致。

不叠加大尺度、无方向的噪声透明斑块，也不加白点伪装纸纹。纸齿负责细节，明显漏色由下一层同向蒙版负责。

### 5.4 斜向漏色蒙版

漏色由 `mask` 从颜料中减去，缺口与平涂笔触同为 −30°，形成细长、两头渐尖的形状：

| 参数 | 当前值 |
| --- | --- |
| 漏色通道间距 | 12–14px |
| 单个缺口长度 | 18–38px |
| 名义厚度 | 1–3px，再叠加局部 .8–1.2 的宽度系数 |
| 缺口宽度包络 | `sin(πt)`，两端归零、中间稍宽 |
| 缺口中心轻微摆动 | `sin(πt) × .6px` |
| 形状采样 | 两侧各 9 个点，闭合后贝塞尔平滑 |
| 去除强度 | .55–.85，保留部分颜料，不是处处挖空 |
| 沿笔触的额外间隔 | 单个长度之外再留 18–58px |

各通道起点、长度、宽度稍有差异，避免像等距栅栏；但所有变化仍沿同一方向展开。调整时优先保留方向、渐尖形状与断续节奏，不能替换成随机圆点、斑驳大洞或不规则块状漏色。

### 5.5 黄色与选中蓝色的关系

黄色是底部导航的整体色面，选中 Tab 的蓝色单独绘制。渲染黄色时，先用选中项的圆角轮廓及其实际偏移，在黄色颜料组的蒙版中让出对应区域。这样浅蓝不会因为叠在黄色上变绿，也不会依赖白色底板隔开两种颜色。

保留这一蒙版机制，不能简单用半透明蓝色背景覆盖整条黄色导航。

## 7. 复用与开发接入

### 7.1 Vue 模板接入

复用 `.sketch` 接入轮廓，用 `data-pencil` 选择彩铅色阶，加上全局 `v-sketch` 指令在挂载和更新后自动绘制。没有 `data-pencil` 时只画勾线；`.pencil-fill` 是透明底面的辅助类，本身不生成纹理。

```html
<!-- 只有铅笔轮廓的按钮 -->
<button v-sketch class="sketch action-button" type="button">查看详情</button>

<!-- 有彩铅填色的按钮 -->
<button v-sketch class="sketch pencil-fill action-button" data-pencil="yellow" type="button">
  查看详情
</button>

<!-- 后续业务卡片：内容与留白由业务组件确定 -->
<article v-sketch class="sketch pencil-fill activity-card" data-pencil="mint">
  <h2>活动标题</h2>
  <p>活动说明</p>
</article>
```

这些示例用于说明接入方式，尚未加入业务页面。新组件仍需单独定义排版尺寸、内边距和行高；不能只加 `.sketch` 后让文字直接贴在勾线上。沿用全局字体与透明背景，不叠加默认实线 border、实心 CSS 背景或整体旋转。

例如，新组件至少应显式去掉浏览器默认按钮底色，并设置内容留白。下面的尺寸是后续组件的起步示例，不是已经完成的业务组件规格：

```css
.action-button,
.activity-card {
  background: transparent;
}
.action-button {
  min-height: 44px;
  padding: 10px 16px;
}
.activity-card {
  padding: 16px;
}
.activity-card h2 {
  font-weight: inherit;
}
```

`src/main.js` 统一安装路由、`v-sketch` 插件并加载公共 CSS，页面不需要自行添加 `<script src>`。常规 Vue 模板中的挂载、更新和配色变化由指令处理；若在 Vue 之外添加 DOM，可在更新完成后手动调用：

```js
window.HandDrawn.refresh();
```

`refresh()` 当前识别 `.sketch`、`.nav-item`、`.bottom-nav`、`.page-outlet` 及非通知类 `.icon-button`。新建通用卡片使用 `.sketch` 即可，不需要复制一份纹理算法。底部导航依靠 `.bottom-nav` 进入开放上沿的特殊绘制流程，不用普通 `.sketch` 代替。

### 7.2 渲染稳定性与层级

渲染器先为所有匹配元素建立记录，再统一绘制；这样父导航可以取得选中子项的种子与轮廓。每个 DOM 元素的记录存于 `WeakMap`，由初始化顺序生成固定种子，颜料、纸齿、缺口和勾线使用由该种子派生的随机序列。

同一 DOM 元素在页面切换或尺寸重绘时保留自己的种子，避免笔迹闪动。新建元素或改变初始化顺序可能改变笔迹；当前种子并不是按业务 ID 持久化的。后续若需要跨组件重建保持完全一致，应在统一渲染器中扩展稳定 ID 机制，不在各业务页面随意调用 `Math.random()`。

`ResizeObserver` 在真实尺寸改变后重画，当前宽高不足 8px 的隐藏/极小元素跳过绘制。缓存键包含尺寸、配色和当前 Tab；相同输入不重复绘制。颜色属性改变也需要刷新：Vue 模板由 `v-sketch` 的更新钩子处理；外部直接修改 DOM 时主动调用 `refresh()`，不能只依赖尺寸观察。

装饰 SVG 使用 `aria-hidden="true"`、`focusable="false"` 和 `pointer-events: none`。宿主有 `isolation: isolate`，SVG 绝对定位、`z-index: −1`，在内容后方但保留在该组件层叠上下文中；`overflow: visible` 留出轻微偏移笔迹。不要把 SVG 放到文字上面，也不要因父层裁剪切掉勾线。

Vue 与 RouterLink 更新可能重写宿主的 class 或子内容。每次刷新会恢复 `has-sketch` 层叠类及原装饰 SVG，同时保留已分配的种子；不要用频繁删除、重新初始化的方式恢复纹理。

### 7.3 当前组件与渲染生命周期

`src/App.vue` 管理手机框架、路由视图与占位通知；`AppHeader`、`PageHeading`、`PageFooter`、`BottomNav` 提供公共结构，`PagePlaceholder` 提供当前占位展示。所有页面只负责自己的内容，不重复编写公共框架。

`src/plugins/sketch.js` 注册全局 `v-sketch` 指令。同一帧内多个组件的 mounted/updated 合并到一次 `requestAnimationFrame`，等 Vue 完成 DOM 更新后测量并绘制。`beforeUnmount` 调用 `release(element)` 取消该元素的尺寸观察并移除装饰 SVG；应用卸载调用 `dispose()` 清理观察器与待执行帧。`refresh()` 同时回收已断开连接的元素，避免反复路由切换残留观察目标。

`sketch.js` 已改为 ES 模块，公开 `createHandDrawnRenderer()`，实例提供 `refresh()`、`release()`、`dispose()`。常规页面只使用指令，不能在每个页面单独创建渲染器。渲染器保持按真实像素尺寸绘制；字体文件、透明底层、涂抹方向和轮廓参数沿用本规范。

### 7.4 团队并行工作方式

每个 `src/pages/*Page.vue` 自己导出 `pageMeta`，包含 `key`、`id`、`title`、`placeholder`、`label`、`eyebrow`、`icon`、`accent`、`nav` 和 `back`。需要整页替换公共框架时，额外设置 `shell: "focus"`；`App.vue` 据此隐藏共享页眉、标题栏、页脚和底部导航，并去掉内容区内边距，安全区由该页自己留出。未设置 `shell` 的页面继续使用完整框架。`src/router/index.js` 自动发现这些文件，按 ID 排序并生成哈希路由；`nav` 决定底部导航归属，`back` 决定标题栏是否显示返回入口。D-01 目前使用 `focus`。第一页是登录/注册，没有「初次设置」页眉。选「登录」后「登录并进入」直接进入活动地图 `#/map`；选「注册」后「注册并继续」让中间内容在约 0.32s 内向左滑出，授权页从右侧进入；这一步顶部的品牌卡片、「初次设置」卡片和底部按钮也从右侧一起滑入。顶栏和底栏浮在内容之上，滑出的注册页保持原来的高度，按钮不被裁切。授权页「下一步」再左滑进入兴趣页，该页不提供跳过；这两页之间切换时，页眉和底部按钮不跟着平移。授权页和兴趣页都可以「返回上一步」；「开启校园生活」和「暂时跳过」都进入活动地图。返回时方向相反。系统开启减少动态效果时不播放这段滑动。用户名、密码和注册页的确认密码只作界面，暂不校验、不匹配。位置和通知默认未打开，按钮为白底「去设置中打开」；点击后变为黄底「已允许」，再点回到白底。只改本页状态，不调用系统权限。性别默认选中「保密」。选中时男生为蓝色、女生为粉色、保密为黄色。

日常开发只需在负责页面的 `<template>` 中替换 `<PagePlaceholder :page="pageMeta" />`，逻辑写在 `<script setup>`，专属样式写在本页 `<style scoped>`。需要子组件时可放在 `src/pages/<页面名>/`，只由该页面导入；不要命名为顶层 `*Page.vue`，以免被识别为独立路由。

已有页面补内容无需修改 `index.html`、路由清单或其他页面文件。新增页面才需要新增顶层 `*Page.vue`，并提供唯一的 `pageMeta.key` 和合适的 ID；新 Tab 项属于公共导航变更，需要统一调整 `BottomNav.vue`。目前保留七个业务页面和五项导航，原有业务页面 ID 不重新编号。

`styles.css`、`sketch.js` 和 `src/components/` 是公共基线。页面专属布局优先留在 scoped 样式里；公共样式或共享组件的修改应由团队集中协调，并同步更新本规范。`node_modules/`、`dist/` 不提交；`package-lock.json` 提交，以便团队用 `npm ci` 安装一致依赖。

## 10. D-02 地图的展示约定

活动地图的需求、状态、模型参数及文件分工见 [地图设计说明](./src/pages/map/README.md)。地图操作按钮、地图标签、筛选和活动卡复用本规范的手绘指令与本地字体，不能另换为普通纯色按钮。

WebGL 地图区域也遵循彩铅平涂与轻微黑铅勾线的视觉语言。当前楼体直接使用 UI 的亮黄色笔触色：`#ffd600`、`#ffdf16`、`#ffe93d`、`#fbd21a`；现代屋顶用品牌黄 `#ffdf32`，传统屋顶用薄荷绿 `#83cbb4`，窗格为与 APP 背景一致的白色 `#ffffff`，湖水为明亮天蓝 `#7dd6fa`。配色集中在 `src/pages/map/map-palette.mjs`，优先表达软件主题，原 OSM 实景标签不改写。地面使用嫩绿 `#c2ef98`，草地 `#a6e879`，树冠使用五种明亮浅绿，道路底色为白色 `#ffffff` 并保留彩铅纹理。天空直接使用 APP 主样式 `--blue` 的 `#9ac8f2`，远景雾与天空同色，在 650–2000m 间渐隐，避免远方地面与天空出现硬边。玻璃、水面不做亮面金属或强反光。画布之外继续保持透明背景。

材质先混入 4% 暖纸色，再绘制纹理；最终画面保留 55% 原始填色、45% 漫反射与阴影，并使用 `NoToneMapping` 避免摄影式映射压低主题色。不要只增大灯光强度来提亮，否则会冲掉笔触层次。默认视角高度约 95m、距离约 220m，围绕示例定位点，以约 26° 俯角观看附近建筑，让初始界面即可看到立面和填色纹理。

3D 材质统一使用 `src/pages/map/pencil-material.mjs`：局部表面坐标投影、约 -30° 的宽笔触叠色，以深浅变化为主，少量同向短漏色为辅。纹理在模型坐标中固定，无时间随机数、每帧重新抽样或外网贴图；旋转、缩放、楼层升降不会使颜色游走。远处用屏幕导数减弱高频颗粒，防止缩放产生摩尔纹和闪烁。当前平涂参数为基础露纸混合 0.10、宽笔触变化 ±0.085、搭接变化 ±0.035、纸齿 ±0.03、局部漏色增量最多 0.32；所有数值进入最终 0.025–0.46 的纸色混合范围。`scale` 控制不同对象的纹理密度，调色时先改变基础颜色，避免把漏色加大成随机白洞。

模型勾线只描实体折角、檐口、窗格、楼板等结构边缘，不画满三角网格。黑铅色 `#383d39`，常用透明度约 0.35–0.52，背景建筑 0.18，湖岸 0.28。折角筛选约 35–42°，长线每约 2.5m 分段，局部波动上限 0.045m，端点收零；线条需保持轻微、连贯，不夸张扭曲实体。树冠使用实例化背面描边外壳，仅比原冠放大约 2.2%，不逐面勾线。圆润树冠、不同浅绿和哑光填色共同营造手绘风景感。

分层前后必须使用同一建筑、同一楼层几何、同一窗格与同一屋顶对象。楼体在初始化时按真实轮廓水平裁切；展开仅插值各层的位置，室内示意逐渐显现。收起反向插值到原始层高；中途重选从当前进度继续，不重建或重置首帧。相机与楼层共用约 1050ms 的平滑缓动，楼层标签跟随当前层位置，地图画布不因选中建筑突然改变高度。系统减少动画偏好开启时直接到位。浅蓝楼板和教室地板表示选中层与活动；展示间距和室内分隔仍是示意。具体实现、来源与近似范围见 [建模说明](./src/pages/map/MODELING.md)。

首页下方信息以抽屉承载，复用 `src/pages/map/ActivityDrawer.vue`。提供三个停靠档位：默认中间档占 `.phone-shell` 实际高度的 25%；展开档一直到页眉分割线，高度为手机框架减去页眉与 Tab；隐藏档只保留 38px 高的滑动把手。底部始终固定在 Tab 上方，短屏按实际可用空间限幅。抽屉采用白色底及贯穿全宽的直线黑铅分隔，不使用上沿圆角，以完整遮挡后方地图、避免顶角漏出蓝色背景；内容卡片继续复用彩铅填色。使用 620ms、`cubic-bezier(.22, 1, .36, 1)` 的高度过渡，拖动时关闭过渡以保持跟手，减少动画偏好开启时直接到位。

提示统一为「上滑发现更多，下滑隐藏内容」；隐藏档只显示滑动把手，不显示提示或内容，并通过 `inert` 避免焦点落入隐藏内容。顶部把手支持拖动、点击与键盘上下箭头；隐藏档点击或上滑即可恢复中间档，继续上滑展开。中间档下滑隐藏；展开档短下滑返回中间档，长距离拖动可直接隐藏。展开后正文独立滚动，到达顶部再下拉可换档。横向卡片滑动不改变抽屉高度，手势结束后避免误触活动。首次进入建筑探索时记住操作前的抽屉档位，并平滑切到中间档展示建筑信息；切换建筑或从活动详情返回时不覆盖这份记录。「返回」或取消建筑选中时带动画恢复进入前的档位，并保持地图当前视角。复位 / 定位按钮只复位地图与楼层，保留操作当下的抽屉档位，同时清除本次建筑探索记录；切换 2D/3D 时保留当前建筑、楼层与该记录，继续查看同一处活动。

地图画布完整延伸到 Tab；相机通过固定的视口偏移，把聚焦中心保留在默认抽屉上方的可视区，并绘制下方被抽屉覆盖的区域。三档切换只改变覆盖高度，不重新布局画布、移动相机或重建模型；隐藏后新增可视区显示真实地图，不留纯蓝色空白。2D 共用同一抽屉，使用 Canvas 绘制北向俯视地图，配色、纹理和建筑轮廓复用 3D 数据。

地图右侧控制列只保留放大 `＋`、缩小 `−`、示例定位 `◎` 三项。定位同时负责收起分层与返回默认视角，不再另设「回到初始视角」按钮。「返回」与点悬空屋顶取消选中仅平滑合拢模型，保留当前相机位置、缩放、朝向及观察目标；若聚焦动画尚未结束，取消剩余相机移动。返回默认视角仅由定位入口触发。

地图页设置 `pageMeta.immersive`，标题区缩小、占位页脚省略，给三维场景留出空间，公共页眉和五项 Tab 保留。其他页面仍使用原有框架尺寸。地图交互不引入整体倾斜、夸张勾线或新的字体。


## 11. LiLi 智能助手

智能助手展示四条固定示例消息，沿用公共小赖字体、铅笔轮廓和五色彩铅池。气泡颜色在页面创建时无重复随机分配，交互时保持稳定。LiLi 原样复用活动日历的定位热气球品牌图标作为头像。消息独立滚动，输入区常驻在底部 Tab 上方；左侧历史抽屉占手机框架宽度的 2/3。复制、编辑、撤回、赞踩和本地附件选择可交互，发送与重新生成保留为占位。页面布局、组件及服务接入边界见 [LiLi 页面说明](./src/pages/agent/README.md)。


### 2D 俯视地图

`CampusPlan.vue` 与 3D 共用离线地图、示例定位、屋顶配色和树冠分布。现代屋顶亮黄，传统屋顶薄荷色，边缘呈现黄色墙体，湖水浅蓝、道路白色、绿地与树冠明亮。周边保留真实建筑轮廓，以浅纸色淡化；校界只限制观察中心。图书馆等建筑庭院保留空洞，不用矩形替代实际轮廓。

`plan-pencil.mjs` 在米制坐标生成稳定的 -30° 宽笔触平涂：浓淡交叠、少量同向渐尖漏色、细纸齿，避免稀疏排线、无方向白洞或均匀纯色。Canvas 图案随地图移动与缩放，不重新随机；轮廓为轻微圆滑起伏，黑铅宽度约 1px，选中用蓝色描边。地图标签继续使用 `v-sketch` 与小赖字体，并避让控件和彼此。

北向俯视保持水平，不旋转；初始定位中心与 3D 一致。建筑选择平滑聚焦，取消选择保持当前位置。2D/3D 切换共享建筑、楼层、筛选与抽屉，2D 点建筑或搜索保持 2D。指北针、米制比例尺只作为地图的轻量辅助信息，不增加主导航模块。
