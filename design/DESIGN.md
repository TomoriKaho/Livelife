# PKU LiveLife · 手机端统一设计规范

本目录是供开发组参考和复现的静态 UI 原型。页面范围来自 [issue #13](https://github.com/TomoriKaho/Livelife/issues/13)，视觉参考为 `picture_reference/0.png`、`1.png`、`2.png`。

本文记录截至 2026-10-03 经多轮调整确认的公共视觉基线，供后续页面设计、组件扩展及开发复现使用。参数以当前 `styles.css`、`sketch.js` 为准；后续修改公共样式时同步更新本文件。业务模块与页面数量由 issue 决定，参考图用于确定视觉语言，不直接照搬其中的业务内容。

## 打开方式

直接用浏览器打开 `index.html` 即可，无需安装依赖或构建。也可以在仓库根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory design
```

然后访问 `http://127.0.0.1:8765`。电脑端仍然呈现手机布局，最大宽度 430px；窄屏铺满视口。页眉和底部导航固定在框架中，内容区单独滚动，并预留移动设备安全区。

## 1. 视觉语言与统一原则

整体方向是明亮、轻松、圆润的校园手绘界面。深蓝铅笔勾线确定轮廓，明黄建立品牌与导航识别，浅蓝表示当前选择；薄荷绿、粉红、淡紫提供辅助层级。字形柔和，色面有笔触与浓淡，布局本身保持整齐。

以下规则是已经确认的公共基线：

1. **轮廓轻微不规则，但平滑克制。** 保留手画时的小幅起伏和复描，不能出现明显锯齿、剧烈抖动或夸张扭曲。
2. **勾线保留圆角，CSS 底面保持透明。** 圆角属于 SVG 轮廓及其填色裁剪形状，不用一个实心 CSS 圆角矩形垫在下面。此前“去掉背景圆角”的要求不表示把勾线改成直角。
3. **彩铅采用宽笔触、密集平涂。** 先形成连续色面，再表现沿同一方向的浓淡和少量漏色。避免细线排线、稀疏斜线、随机大面积白洞或完全均匀的纯色。
4. **漏色跟随斜向涂抹。** 使用细长、渐尖、断续的斜向缺口，不用无方向的散点或云状斑块。
5. **黄色明亮、饱和。** 保留纸齿和深浅变化，但整体不能变成灰黄、土黄或过浅的奶油色。
6. **组件整体水平摆放。** 品牌、按钮、卡片不做整体旋转。少量装饰短线、星芒可以有局部角度，不能带动内容倾斜。
7. **中英文统一采用圆润手写字体。** 当前使用小赖字体；正文、标题、按钮、导航均继承同一字族，不混入楷体、黑体或棱角突出的展示字体。
8. **内容与轮廓之间留出空间。** 图标和文字应比按钮小一圈；增加触控区域时优先扩大容器，不同步放大里面的内容。

参考图的作用是校准明黄、浅蓝、深蓝线条、品牌比例和导航层级。当前页面中的占位框、占位说明与页面目录是设计审阅设施，后续业务内容不必复制这些占位装饰。

### 2.3 透明背景的准确含义

`:root`、`body`、`.phone-shell`、按钮、卡片的 CSS 底层使用 `background: transparent`。彩铅颜料本身仍有颜色和透明度；其上叠加纸齿滤镜和漏色蒙版。透明并不意味着删掉黄色或蓝色填色。

浏览器默认画布可能显示为白色，这不是原型绘制的白色背景。不要为了“纸感”重新添加整页纸色、白色卡片底或纹理底图。`assets/pencil-grain.svg` 当前不参与绘制。

## 4. 铅笔勾线与边缘绘制

### 4.1 通用按钮、卡片轮廓

统一复用 `sketch.js` 的 `perimeter()` 与 `pathFor()`。轮廓按元素真实的 `clientWidth`、`clientHeight` 绘制，流程为：圆角矩形采样 → 小幅坐标偏移 → 二次贝塞尔平滑 → 主线、复描、局部压力叠加。

| 参数 | 当前实现 |
| --- | --- |
| 轮廓内缩 | 4px，给线宽与轻微偏移留余量 |
| 圆角半径 | `min(15, height / 3, width / 4)`，单位 px |
| 圆角采样 | 每个四分之一圆弧分成 9 段，含端点 10 个采样点 |
| 直边采样 | 约每 5px 一个点 |
| x 方向起伏 | `sin(i × .34 + seed) × .6 + (rng − .5) × .45` |
| y 方向起伏 | `sin(i × .27 + seed × .7) × .55 + (rng − .5) × .4` |
| 复描偏移 | 第二遍 x 增加 .2px、y 减少 .16px，并使用不同的固定随机序列 |
| 平滑方式 | 相邻点取中点，使用连续二次贝塞尔 `Q` 连接 |

坐标起伏量级在约 1px 以内，平滑后更克制。不能随组件尺寸等比例放大抖动，也不能把采样点用粗折线直接连接。圆角轮廓与彩铅裁剪共用同一条路径，色面形状与勾线一致。

### 4.2 线条层次

| 层 | 线宽 | 不透明度 | 用途 |
| --- | --- | --- | --- |
| 主勾线 | 1.65px | .92 | 深蓝主体轮廓，圆滑转角 |
| 偏移复描 | .65px | .54 | 模拟铅笔轻微重复描画 |
| 局部短勾线 | .6–1.5px | .2–.75 | 模拟局部压力变化，圆头短线 |
| 当前占位区主线 | .85px | .4 | 低存在感的大占位框，颜色 `#7f91a3` |
| 当前占位区复描 | .65px | .24 | 与占位主线配合；不叠加局部重线 |

主线和复描采用圆滑连接，局部短线使用圆头。局部加深应断续、轻量，不能让整圈轮廓都变成两条明显平行线或厚重黑边。弱占位框的参数是当前占位专用，业务卡片默认采用通用轮廓。

部分组件保留彩铅偏移笔迹：品牌、目录按钮、目录条目、占位纸片与选中 Tab，沿轮廓采样点的前约 58% 画一条 3.6px、透明度 .72 的短色线，偏移 `(2px, 3px)`。占位纸片偏蓝，其他偏黄。这是有限范围的辅助笔迹，不是实心阴影，也不默认应用到所有业务卡片。

### 4.3 Tab 栏的特殊边缘

整条 Tab 栏不能套用通用闭合四边框，必须使用 `topEdge()`：

- **只有上沿勾线。** 左、右、下不画长侧边或底边，黄色色面直接贴住手机框架。
- **左上、右上有圆角。** 半径为 `min(14, width / 8)`；两端圆弧将上沿自然接到左右边缘。圆弧属于上沿，不继续向下画侧边。
- **中间总体平直。** 不加入中心下凹、拱起或波浪；仅保留细微手绘起伏。
- 上沿基准为 SVG 内 y=2.5px；第二遍复描上移 .16px。直段扰动为 `sin(πi / steps) × [sin(i × .3 + seed) × .35 + (rng − .5) × .3]`，让起伏在两端衰减。
- 填色裁剪路径沿上沿走完，再连接右下、左下闭合；**裁剪闭合不代表勾线闭合**。勾线路径始终开放。
- 当前选中 Tab 的浅蓝小框仍采用通用圆角闭合轮廓，与整条黄色导航带的开放上沿区分开。

“两端有一点向下的弯曲”指左上、右上圆角，不指整条上沿中间向下弯。

## 5. 彩铅纹理绘制方法

### 5.1 期望观感与合成顺序

目标是斜向、宽笔触的彩铅平涂：远看色面连续，近看有交叠、深浅和少量同向漏色。浓淡变化占主导，缺失颜料只是细节。

当前 SVG 合成顺序如下：

1. 使用勾线轮廓建立 `clipPath`，限制颜料范围。
2. 画带透明度的浅颜料层，使用该色阶的第三个颜色。
3. 叠加两遍同向的宽笔触，颜色与笔压变化形成深浅。
4. 对整组颜料应用纸齿透明度滤镜。
5. 应用与笔触同方向的渐尖缺口蒙版，少量去除颜料。
6. 将色面裁剪到轮廓内部；选中 Tab 另有区域蒙版，避免黄色与蓝色混色。
7. 在颜料上绘制辅助色笔迹、主勾线、复描和局部石墨线。

浅颜料层也经过滤镜和蒙版，不是放在纹理下的不透明底板。蒙版里的黑白只控制透明度，不会作为黑白色块画到页面上。

### 5.2 同向宽笔触

颜料和漏色共用 `pencilSpace()` 中 **−30°** 的旋转坐标。在屏幕上表现为由左下向右上延伸的斜向平涂。通过 `along`（顺着笔触）、`across`（跨越笔触）两个坐标生成纹理，不为不同组件随意改变方向。

| 参数 | 当前值 | 视觉作用 |
| --- | --- | --- |
| 浅颜料层透明度 | 黄色 .72，其他 .54 | 黄色更明亮饱和，其他保持柔和 |
| 平涂遍数 | 2 遍，第二遍横向笔触坐标起点偏移 2px | 密集交叠形成连续色面 |
| 笔触行距 | 4.5–5.3px | 行距明显小于笔触宽度，避免稀疏排线 |
| 笔触宽度 | 12–18px，圆头 | 体现较粗彩铅平涂 |
| 单段长度 | 30–85px | 打散机械的整条条纹 |
| 相邻段交叠 | 8px | 色面衔接，减少突兀断口 |
| 每段采样 | 5 段、6 个点，贝塞尔平滑 | 笔触轻微自然起伏 |
| 跨笔触方向摆动 | `sin(along / 22 + seed) × 1.3 + (rng − .5) × .6` | 轻微不齐，仍保持整体方向 |
| 笔触基础透明度 | .11–.23，再乘笔压 | 通过交叠产生浓淡，不靠纯色块 |

笔压计算为：

```text
pressure = .72
         + .23 × sin(center / 48 + row / 17 + seed)
         + .17 × sin(center / 87 − row / 29)
opacity  = (.11 + random × .12) × pressure
```

其中 `center` 是当前笔触段的中心，`row` 是跨笔触坐标。变化沿笔触展开，而不是每个像素都随意换深浅。增加密度时优先调整交叠、颜料透明度或纸齿覆盖，不把笔触变回细线，也不取消浓淡差异。

### 5.3 纸齿透明度滤镜

纸齿模拟颜料在细小纸纹上的附着差异，只用于细尺度质感：

- `feTurbulence`：`type="fractalNoise"`，`baseFrequency=".85"`，`numOctaves="3"`，固定种子。
- `feColorMatrix`：颜色通道不用于输出色彩，将噪声 RGB 按 `.28 / .53 / .19` 加权转成 alpha。
- `feComponentTransfer`：alpha 线性映射，`slope=2.6`；黄色 `intercept=−.38`，其他 `−.5`。黄色覆盖更实，避免被透明度冲淡。
- `feComposite`：`SourceGraphic in paperCoverage`，保留颜料原色，按纸齿覆盖度改变透明度。
- 滤镜采用 `sRGB`，范围与组件尺寸一致。

不叠加大尺度、无方向的噪声透明斑块，也不加白点伪装纸纹。纸齿负责细节，明显漏色由下一层同向蒙版负责。

### 5.4 斜向漏色蒙版

漏色由 `mask` 从颜料中减去，缺口与平涂笔触同为 −30°，形成细长、两头渐尖的形状：

| 参数 | 当前值 |
| --- | --- |
| 漏色通道间距 | 12–14px |
| 单个缺口长度 | 18–38px |
| 名义厚度 | 1–3px，再叠加局部 .8–1.2 的宽度系数 |
| 缺口宽度包络 | `sin(πt)`，两端归零、中间稍宽 |
| 缺口中心轻微摆动 | `sin(πt) × .6px` |
| 形状采样 | 两侧各 9 个点，闭合后贝塞尔平滑 |
| 去除强度 | .55–.85，保留部分颜料，不是处处挖空 |
| 沿笔触的额外间隔 | 单个长度之外再留 18–58px |

各通道起点、长度、宽度稍有差异，避免像等距栅栏；但所有变化仍沿同一方向展开。调整时优先保留方向、渐尖形状与断续节奏，不能替换成随机圆点、斑驳大洞或不规则块状漏色。

### 5.5 黄色与选中蓝色的关系

黄色是底部导航的整体色面，选中 Tab 的蓝色单独绘制。渲染黄色时，先用选中项的圆角轮廓及其实际偏移，在黄色颜料组的蒙版中让出对应区域。这样浅蓝不会因为叠在黄色上变绿，也不会依赖白色底板隔开两种颜色。

保留这一蒙版机制，不能简单用半透明蓝色背景覆盖整条黄色导航。

## 6. 手机布局与公共组件

### 6.1 手机框架与滚动

| 项目 | 当前规范 |
| --- | --- |
| 框架宽度 | `min(100%, 430px)`，电脑端也不扩成桌面多栏 |
| 最小页面宽度 | 280px；常用手机检查重点为 320、375/390、430px |
| 手机视口高度 | `100dvh`，保留 `100vh` 回退 |
| ≥600px 的外层视口 | 手机框架居中，外层 padding 24px；框架高 `min(880px, 100dvh − 48px)` |
| 框架结构 | 纵向 flex，页眉/Tab 不收缩，内容区 flex 占满剩余空间 |
| 内容滚动 | `.page-main` 设置 `min-height: 0; overflow-y: auto` |
| 安全区 | 页眉加 `safe-area-inset-top`，Tab 加 `safe-area-inset-bottom` |

当前页眉与 Tab 位于滚动内容之外，留在手机框架内；不是额外覆盖内容的 `position: fixed` 浮层。新增页面继续使用这一结构，避免内容被导航遮住或出现整页与内容区双重滚动。

### 6.2 页眉、标题与页脚

- 页眉常规左右留白 17px，上方 17px 加安全区，下方 14px。品牌、校区、通知在同一行，间距 10px；≤359px 左右 15px，同行间距 4px。
- 品牌使用黄色彩铅底与闭合铅笔轮廓。铃铛不另套卡片框，保留小珊瑚红圆点及黄色提示短线。
- 内容区上方 22px、左右 17px；≤359px 左右改为 15px。标题栏左右布局，标题与目录按钮间隔 8px，下方留 19px。
- 目录按钮最小高度 44px、左右内边距 12px、图文间距 5px；图标 14px。
- 当前页脚最小高度 57px，文字居中、字号 11px、两侧装饰与文字间距 10px。它是弱化的公共收尾，不应成为业务页面的主信息。
- 当前大占位区最小高度 310px，其浅色框仅用于占位展示。新增业务内容可重新分配高度与卡片结构。

### 6.3 底部 Tab 栏与内容比例

顺序固定为 **活动地图、活动日历、兴趣广场、智能助手、我的**，五项等宽分配。只有当前项显示浅蓝填色与完整勾线框；非当前项只有图标、文字，不能把每个 Tab 都画成小卡片。

| 项目 | 当前值 |
| --- | --- |
| 整条导航内边距 | 上 5px、左右 10px、下 `9px + safe-area-inset-bottom` |
| ≤359px 左右内边距 | 8px |
| Tab 之间间距 | 2px |
| 每项高度 | 最小 70px，点击区域保留完整容器 |
| 每项内边距 | 上下 8px、左右 6px |
| 图标与标签间距 | 5px |
| 标签行高 | 1.2，保持单行 |
| 图标尺寸 | `clamp(22px, 42cqi, 26px)`，宽高相同 |
| 标签字号 | `clamp(10px, 21cqi, 12px)` |
| 缩放依据 | 每个 `.nav-item` 使用 `container-type: inline-size`，`cqi` 取该按钮内容盒宽度 |
| Tab 图标线宽 | 2.2，选中图标颜色 `#245888` |

在 430px 框架中，图标为 26px、标签为 12px；320px 窄屏中，图标为 22px、标签为 10px。当前四字标签在 320px 布局中距离按钮左右盒边约 10px，勾线本身另内缩约 4px，仍有可见留白。

不得通过放大图标、字体填满选中框。缩放内容时保留容器高度与点击区域；需要支持更长文案时，先重新评估标签与布局，不突破已有字号上限。Tab 栏的外边缘遵循第 4.3 节，选中框内部内容遵循本节，两者分别处理。

### 6.4 图标与小装饰

使用 `index.html` 中的本地 SVG symbol 与 `<use>`，图标基准 `viewBox="0 0 32 32"`。通用图标默认 26px、线宽 2.1、圆头与圆滑连接，颜色继承 `currentColor`。地图、人物采用实心形状；日历、星星、机器人等采用线描，机器人眼睛为点状。

新增图标应延续简洁轮廓和圆滑笔画，避免混入极细线、尖锐几何图标、立体渐变或不同图标字体。图标不必套用卡片级随机轮廓算法；手绘卡片与简洁图标一起构成层级。通知铃铛当前为 32px，校区定位图标为蓝色 `#398def`。

星芒、短横线、黄蓝偏移笔迹是少量点缀。不要给每个卡片添加一整套装饰，也不要用真实阴影、镜面渐变或发光替代彩铅笔迹。

### 6.5 状态、弹层与交互

- 当前选择使用 `aria-current="page"`，Tab 同时设置 `data-pencil="blue"`；离开时移除属性和填色，不只依赖颜色表达状态。
- 按下时按钮与 Tab 只下移 1px；不旋转、不放大、不重新随机生成笔迹。
- 键盘焦点使用 3px、`#456e99` 的清晰轮廓，偏移 5px。保留焦点可见性，不能为了手绘效果去掉可操作提示。
- 通用图标按钮当前为 44×44px，标题返回按钮是现有的 30px 宽特殊入口。后续业务按钮应根据操作场景保留足够的触控区域。
- 页面目录宽 `min(390px, 100% − 32px)`、内边距 23px，自身底层透明，外层遮罩为 90% 白色加 6px 背景模糊。遮罩是弹层分隔手段，不是常态页面背景。
- 目录条目最小高度 44px、内边距 10px 12px、间距 7px，当前条目使用浅蓝填色。
- 通知当前只显示 2600ms 的占位 toast；后续业务通知需另行设计。toast 本身透明且复用勾线。
- 占位内容只有 .22s 的淡入与 5px 上移，在 `prefers-reduced-motion` 允许时播放。此动效不能推广成所有卡片的持续摇晃或随机抖动。

## 7. 复用与开发接入

### 7.1 静态 HTML 接入

复用 `.sketch` 接入轮廓，用 `data-pencil` 选择彩铅色阶。没有 `data-pencil` 时只画勾线；`.pencil-fill` 是透明底面的辅助类，本身不生成纹理。

```html
<!-- 只有铅笔轮廓的按钮 -->
<button class="sketch action-button" type="button">查看详情</button>

<!-- 有彩铅填色的按钮 -->
<button class="sketch pencil-fill action-button" data-pencil="yellow" type="button">
  查看详情
</button>

<!-- 后续业务卡片：内容与留白由业务组件确定 -->
<article class="sketch pencil-fill activity-card" data-pencil="mint">
  <h2>活动标题</h2>
  <p>活动说明</p>
</article>
```

这些示例用于说明接入方式，尚未加入业务页面。新组件仍需单独定义排版尺寸、内边距和行高；不能只加 `.sketch` 后让文字直接贴在勾线上。沿用全局字体与透明背景，不叠加默认实线 border、实心 CSS 背景或整体旋转。

例如，新组件至少应显式去掉浏览器默认按钮底色，并设置内容留白。下面的尺寸是后续组件的起步示例，不是已经完成的业务组件规格：

```css
.action-button,
.activity-card {
  background: transparent;
}
.action-button {
  min-height: 44px;
  padding: 10px 16px;
}
.activity-card {
  padding: 16px;
}
.activity-card h2 {
  font-weight: inherit;
}
```

脚本顺序保持 `sketch.js` 在 `app.js` 之前。新增 DOM 或改变 `data-pencil`、选中状态后调用：

```js
window.HandDrawn.refresh();
```

`refresh()` 当前识别 `.sketch`、`.nav-item`、`.directory-link`、`.bottom-nav`、`.page-outlet` 及非通知类 `.icon-button`。新建通用卡片使用 `.sketch` 即可，不需要复制一份纹理算法。底部导航依靠 `.bottom-nav` 进入开放上沿的特殊绘制流程，不用普通 `.sketch` 代替。

### 7.2 渲染稳定性与层级

渲染器先为所有匹配元素建立记录，再统一绘制；这样父导航可以取得选中子项的种子与轮廓。每个 DOM 元素的记录存于 `WeakMap`，由初始化顺序生成固定种子，颜料、纸齿、缺口和勾线使用由该种子派生的随机序列。

同一 DOM 元素在页面切换或尺寸重绘时保留自己的种子，避免笔迹闪动。新建元素或改变初始化顺序可能改变笔迹；当前种子并不是按业务 ID 持久化的。后续若需要跨组件重建保持完全一致，应在统一渲染器中扩展稳定 ID 机制，不在各业务页面随意调用 `Math.random()`。

`ResizeObserver` 在真实尺寸改变后重画，当前宽高不足 8px 的隐藏/极小元素跳过绘制。缓存键包含尺寸、配色和当前 Tab；相同输入不重复绘制。颜色属性改变后需要主动调用 `refresh()`，不能只依赖尺寸观察。

装饰 SVG 使用 `aria-hidden="true"`、`focusable="false"` 和 `pointer-events: none`。宿主有 `isolation: isolate`，SVG 绝对定位、`z-index: −1`，在内容后方但保留在该组件层叠上下文中；`overflow: visible` 留出轻微偏移笔迹。不要把 SVG 放到文字上面，也不要因父层裁剪切掉勾线。

### 7.3 Vue 或其他框架迁移

推荐拆分公共结构为 `AppShell`、`AppHeader`、`PageHeading`、`BottomNav`、`PageDirectory`，业务内容放入路由视图。页面清单及导航归属沿用 `app.js` 的 `pages` 元数据，避免复制多套页眉与导航。

在 DOM 挂载和更新完成后调用渲染器；Vue 中可在 `onMounted` 或必要的状态变化后 `await nextTick()`，再调用 `HandDrawn.refresh()`。统一管理 resize 观察与组件卸载时的清理；当前静态渲染器仅公开 `refresh()`，正式组件化时如需销毁接口应集中补充。

迁移时继续按真实像素尺寸重绘 SVG，不把一张小按钮纹理图片拉伸成大卡片；不改变字体文件、透明底层、涂抹方向或主轮廓参数。新增功能与风格调整分开评估，先继承公共基线。

## 8. 后续页面的设计与验收

每个业务页面先确定 issue 要求的模块、内容层级与移动端交互，再套用公共字族、语义色、轮廓与彩铅渲染。页面专属尺寸和状态可以补充，但不要重新发明另一套手绘方法。

完成新页面后，按以下项目与当前公共框架、三张参考图对照：

- 电脑端仍呈现手机布局，320px 窄屏没有拥挤、裁字或横向溢出，390/430px 没有过度放大的按钮内容。
- 页眉与 Tab 留在框架中，内容独立滚动，安全区有效；内容不被导航或弹层遮住。
- 所有文字实际加载小赖字体，中英文一致；标题、正文、辅助文字层级清楚。
- 组件水平摆放；轮廓圆滑、有少量起伏，主线不粗重，复描不过度分离。
- CSS 底层透明，彩铅色面仍存在；没有新增白色卡片底或整页纸色底。
- 黄色明亮饱和，浅蓝选中框不与黄色混成绿色。
- 纹理看起来是密集宽笔触平涂，浓淡主要沿 −30° 展开，纸齿细小、漏色渐尖而断续。
- Tab 只有当前项有完整小框，导航带只有圆角上沿，中间不下凹，左右与底部色面贴边。
- 图标、文字与框线之间有可见留白；长内容通过排版处理，不靠无限缩小字号。
- 尺寸变化后纹理重新绘制；同一控件切换状态不闪烁，装饰不挡点击，键盘焦点可见。

通用规范变更应同时修改 `styles.css` / `sketch.js` 和本文件，并在不同手机宽度、不同长度的文字及至少一个选中状态下检查。当前未实现的业务状态、复杂表单与长正文属于后续页面任务，不视为已经验收通过。
