# 燕园三维外观与景观建模

这版在真实 OSM 平面轮廓上，增加彩色立面、窗框、檐口、收坡屋顶、门廊、树冠、湖岸和光照。目标是可辨认、便于逐栋修订的校园设计模型；不是摄影测量或施工模型。所有几何和材质本地生成，启动不请求外部照片、地图、贴图或接口。

## 真实数据与设计近似

| 项目 | 依据与精度 |
| --- | --- |
| 建筑位置、朝向、轮廓 | 本地 OSM way / multipolygon，保留凹形轮廓和内部庭院，坐标存储至分米；源数据本身不是测绘精度保证。 |
| 多面建筑 | 补充 relation 完整成员后，用端点拼接外/内圈。图书馆保留三个内圈，楼体、屋顶与悬空楼板不填满庭院。缺失成员的开放轮廓不被强行闭合。 |
| 高度与层数 | 原数据优先用 `height`，否则楼层数乘 3.8m，再否则常规模型按三层。保留 `heightSource` 区分来源；人工外观配置另作覆盖，不改写原始地图。 |
| 博雅塔 | 官方资料与照片为参考：八角塔身、十三重密檐、逐次收分、窗洞、基座和塔刹，总高约 37m。檐口尺寸及装饰简化。 |
| 教学楼、图书馆 | 灰砖/暖灰石色墙面、蓝灰玻璃、浅色窗框、层间腰线、女儿墙、设备小箱、台阶与门廊。颜色、窗格数量、入口位置、人工高度与屋顶形态为外观近似。 |
| 传统建筑、西门 | 灰绿收坡屋顶和外伸檐口、米灰墙体、棕红窗框。西门用门柱和横梁留出通道，增加牌匾。通用屋顶按边界距离抬高，不是精确传统屋架。 |
| 讲堂、体育馆 | 讲堂使用抬高的收坡屋顶表达体量，体育馆采用简化弧面屋顶。实际结构与各翼高度仍需逐栋修正。 |
| 未名湖 | 实际水面轮廓、青绿水面、窄岸带、弱波纹。没有真实水深、动态倒影或岸边高差测量。 |
| 植被 | 优先 OSM 树点与树列，余下为固定种子补植，湖岸增加垂柳形态。避开楼体、水面、运动场和道路通道。树种、株高、树冠和补植位置为示意。 |
| 校外背景 | 实际 OSM 轮廓与推定高度、不同暖灰墙色，合并绘制；校外暂不使用校内的详细窗格和屋顶模型。 |
| 室内与活动 | 沿用设计演示数据。楼板沿真实轮廓生成，房间网格、悬空间距和活动为示意。 |

## 文件分工

- `model-profiles.mjs`：以 OSM ID 为键的地标颜色、类型、人工高度和层数。有效的 OSM 六位十六进制颜色标签优先；其余用稳定配置。
- `architecture.mjs`：挤出、窗格、材质、屋顶、博雅塔、西门。增加单栋细节时优先写独立模型函数，不把地标尺寸混进通用生成器。
- `landscape.mjs`：固定种子树木布局、实例化树冠/树干、水面与岸带。
- `rings.mjs`：环拼接与含庭院的 footprint 判断；供地图处理、楼板和景观共用。
- `CampusScene.vue`：光照、相机、选取、分层、聚焦和资源释放。业务页面与演示活动仍分别在 `../MapPage.vue`、`demo.js`。

墙面为粗糙材质；灰砖通过局部坐标生成错缝砖缝，石色墙面只有细微颗粒变化；玻璃粗糙度较低。植物分配不同绿色情况。外层手绘 UI 继续遵守 `design/DESIGN.md`，地图三维材质独立于按钮彩铅纹理。

通用收坡屋顶将轮廓三角面细分两次，再按距外墙/庭院边缘的距离抬高；檐边增加约 0.9m 外伸带，保持庭院开口。屋脊不代表实际测绘结果。博雅塔和弧面体育馆使用独立几何。

树木由三组 InstancedMesh 绘制；窗框与腰线用带顶点颜色的合并几何；周边楼体合为一个对象。静止浏览不重复计算整校阴影，场景变化和分层动画期间更新。组件卸载释放几何、材质、牌匾纹理、控件和 WebGL 资源。

## 交互

初始定位附近视角、校界拖动限制、普通楼层交互沿用原设计。校界不裁断周边景观。普通建筑聚焦时隐藏周围楼体和树冠，保留地形、道路、水面及本栋彩色屋顶；1F 在地面，其余楼板和屋顶悬空。

博雅塔作为风景地标：点击模型或搜索“博雅塔”聚焦完整外观，保留湖岸与周边楼体。十三重密檐不虚构成教室活动层，下方显示地标说明和返回按钮。2D 继续留白。

## 离线数据

`yanyuan-details-osm.json` 保存补充快照，`details-source.json` 保存查询、接口、下载时间和数据时间。查询使用 `out body geom` 以保留 relation 成员 geometry；原 `out tags geom` 只有关系标签与包围盒，不能恢复庭院。

`npm run map:prepare` 只读取本地两套快照。`npm run map:download` 才显式刷新主快照和补充快照后生成展示数据。构建将两套原始快照、来源和许可证一起保存至 `dist/assets/maps/`。当前为 250 栋校内建筑、826 栋周边背景、47 个原始树点；最终树冠包含补植，不能视为实测树木统计。

## 核验

`npm run test:map` 检查校界/投影、活动映射、反向环拼接、开放环拒绝、图书馆庭院不被顶面填平、模型选取标识、有限坐标、树木布局可复现与避让。浏览器另核验实际 WebGL 材质编译、地标聚焦、普通楼层选择、3D/2D 往返及手机布局。CPU 几何测试不代替真实手机帧率测试。
