## 交互状态

1. 每次进入地图页默认 3D，以前端示例定位点为视角中心，展示附近真实 OSM 道路、水面及彩色建筑、屋顶与树冠。初始视角更低、更近，不从整校鸟瞰开始。
2. 点建筑模型、地图标记、建筑快捷按钮、搜索结果或活动卡片，进入建筑聚焦。相机与原模型楼层同步平滑过渡；原窗格、立面、屋顶随同一组部件展开，室内示意逐渐显现。系统减少动画偏好开启时直接到位。
3. 1F 留在地面；上层楼板和屋顶悬空。所有楼板沿建筑外轮廓生成。聚焦时隐藏周围建筑，保留地形、道路和水面参照，避免背景遮挡楼层。三条矮墙和地板表示一个简易房间。
4. 有活动的房间以浅蓝表示；当前楼层的楼板与边线也用蓝色强调。地图楼层标签显示示例教室号，底部楼层按钮显示活动小点。
5. 直接点楼层/房间模型、浮动楼层标签或底部楼层按钮，同步切换活动列表；列表卡片打开本地详情弹窗。Esc 和关闭按钮返回。
6. 点悬空屋顶或「返回」，仅动画合拢建筑并恢复周边场景，保留当前相机位置、缩放、朝向与观察目标；聚焦尚未完成时也停留在点击收起的视角。右侧只保留放大、缩小、示例定位三个按钮，移除单独的「回到初始视角」入口。单指拖动/鼠标拖动旋转、双指缩放/滚轮均可使用；双指或右键拖动平移。
7. 示例定位按钮同时收起当前分层并移到理教附近的蓝点，不读取设备位置。
8. 右上 3D/2D 切换加载对应组件并卸载另一画布。两种模式保留当前建筑、楼层、筛选、抽屉档位及进入探索前的档位记录；2D 内选择建筑或搜索不会自动跳回 3D。2D 缓存本次页面内的平移中心和缩放；有选中建筑时切换模式会聚焦该建筑。未选建筑时 3D 恢复示例定位附近视角，2D 恢复此前平移位置。收藏列表的地图路由仍默认 3D。

## 几何与真实信息边界

底图保存于 `assets/maps/`。原始查询矩形包括校外范围，处理脚本使用 OSM 的「北京大学」校界区分校内互动建筑与周边背景建筑，而非把整个查询框当作燕园。建筑按轮廓中心区分；水面、绿地也分别归入校内及周边集合。校界附近的单个跨界建筑/面要素保留原轮廓，并非对每个面做严格布尔裁切。

校界只约束地图拖动中心，不切断画面。地面连续延伸，周边按实际 OSM 轮廓生成简易模型，远处使用同色雾淡出。`context.roads` 在原始下载范围内保留跨校界道路连续性，场景只渲染这一套道路，避免叠加重影；原 `roads` 仍保留校内裁切结果作数据校验。周边建筑作为背景，不参与校园楼层活动的选择与搜索；背景模型合并绘制以降低绘制调用数。

平移使用地面平面。每帧在 OrbitControls 应用拖动和惯性之后，检查目标点是否位于燕园校界内；校外点回到最近校界，相机同步平移同样的距离，保留观看角度。使用实际凹形多边形，不使用矩形包围盒限制。

当前快照保存 250 栋校内建筑、1639 条校内道路段、12 处校内水面，并新增 826 栋周边背景建筑。包含周边的场景渲染道路共 5481 段。未名湖、博雅塔、理科教学楼、百周年纪念讲堂等来自实际 OSM 数据。米制坐标原点为 `[116.304, 39.9915]`，x 向东、z 向南。坐标保留分米精度；不依赖在线瓦片、地图 SDK、字体服务或 CDN。底图复用原离线快照，并补充建筑多面关系与树木快照。

`demo.js` 的 `demoLocation = [175, 135]` 是唯一的示例定位定义，蓝点、初始视角、定位按钮和返回按钮共用它。`view.mjs` 定义相机相对偏移 `[165, 95, 110]m`，初始相机高度约 95m、观看距离约 220m、俯角约 26°，默认即可看到附近楼体与彩铅笔触。定位蓝点同步缩小为半径 4.5m，避免近景遮挡建筑。修改示例定位时不需要分别修改相机和标记，也不会请求设备定位。

OSM 有 `height` 时使用该高度；否则按 `building:levels × 3.8m` 推定，没有楼层标注时常规地图模型暂按三层。为了演示楼层，理教设四层、讲堂三层、二教五层、一教三层。其余校内建筑按外观配置或 OSM 层数展开最多六个示意层；博雅塔保留完整外观、聚焦观看，不虚构教室层。**这些不代表真实楼层数、室内平面、层高或活动安排。** 内部分隔按轮廓内规则网格生成，不是建筑测绘模型。

楼层展开在原始层高上叠加 `max(16m, max(建筑最大平面尺寸, 45m) × 0.42)` 的额外分离距离。楼体在初始化时按层裁切，点击后不替换原模型；收起时反向归位，中途重新选择从当前进度继续。相机根据平面范围、总分层高度、纵横比和视场角计算容纳整个模型的距离，使用较低的观看角度，减小上层遮挡。用户可继续旋转查看。已增加窗格、檐口、彩色屋顶、树冠与湖岸；来源、程序化生成方式和精度边界详见 [MODELING.md](./MODELING.md)。

## 文件分工与离线启动

- `../MapPage.vue`：搜索、分类、模式切换、底部信息区、详情弹窗、页面状态与专属样式。
- `CampusPlan.vue`：Canvas 2D 俯视绘制、可视范围裁剪、标签避让、指北针/比例尺、单指平移及惯性、双指/滚轮缩放、建筑点选与定位。
- `plan-view.mjs`：屏幕/米制坐标投影、缩放锚点、双指手势、校界约束、建筑命中（排除庭院）、米制比例尺。
- `plan-pencil.mjs`：地图色面的固定彩铅纹理和轻微黑铅路径；不修改原始轮廓数据。
- `CampusScene.vue`：Three.js 模型、OrbitControls、射线选取、相机动画、楼层分离及随相机投影的 DOM 标签。标签复用公共手绘纹理，并缓存按钮子树，避免每帧重画彩铅 SVG。
- `demo.js`：演示建筑、楼层、教室和活动；团队改内容优先在此维护。
- `view.mjs`：以示例位置为目标的初始相机偏移。
- `geometry.mjs`：坐标转换、点在多边形内判断、道路线段裁切、将校外拖动中心约束到最近校界。
- `map-palette.mjs`、`model-profiles.mjs`、`architecture.mjs`、`storeys.mjs`、`pencil-material.mjs`、`landscape.mjs`、`rings.mjs`：建筑外观、几何与风景，分工及精度见 [MODELING.md](./MODELING.md)。
- `scripts/prepare-campus-map.mjs`：从已下载的原始数据生成展示资源。
- `scripts/download-campus-map.mjs`：仅显式刷新数据时访问 Overpass，下载后自动生成展示资源。

在 `design/` 下：

```powershell
npm ci                 # 初次安装依赖需要网络；已有 node_modules 时可跳过
npm run dev            # 地图启动与使用不需要互联网
npm run map:prepare    # 从本地快照重新生成，无网络
npm run test:map       # 校界裁切、投影、资源及活动映射检查
npm run build
npm run preview        # dist 中包含地图、字体和 Three.js
```

仅需要更新底图时执行 `npm run map:download`，此命令需要网络。常规启动与构建绝不运行下载脚本。离线是指依赖已安装后的本地启动，仍通过 Vite 或静态 HTTP 服务提供网页，不是双击 `file://`。

OSM 署名及 ODbL 许可证说明见 `assets/maps/LICENSE.md`。生产构建保留原始地图、转换数据、来源说明和许可证，便于团队分发和追溯。

## 视觉基线

公共字体、按钮和卡片继续遵守 `DESIGN.md`：本地 Xiaolai 圆润手写体、轻微且圆滑的铅笔勾线、饱和黄/浅蓝/薄荷绿/粉色、斜向彩铅平涂的深浅与少量漏色，不整体倾斜。3D 楼体使用 UI 主题亮黄，现代屋顶为品牌黄，传统屋顶为薄荷绿，窗格为与 APP 背景一致的白色，湖水为明亮浅蓝，绿地与树冠一起提亮。展示配色集中在 `map-palette.mjs`，独立于原始 OSM 颜色；弱阴影保留主体填色的明度。全局透明背景保持；WebGL 地图区域的天空与远景雾采用 APP 主题蓝 `#9ac8f2`；明亮草地、树冠和天蓝水面搭配白色道路。模型使用固定在局部表面的宽笔触斜向彩铅平涂、少量同向漏色与轻微黑铅轮廓；水面和窗格为哑光，树冠圆润，参数统一在 `pencil-material.mjs`。

地图页通过 `pageMeta.immersive` 压缩公共标题栏并省略占位页脚，保留页眉与固定底部 Tab。地图固定在正文区域，下方信息通过 `ActivityDrawer.vue` 展示三个档位：默认中间档为手机框架高度的 1/4，上滑展开至页眉分割线，下滑隐藏至 Tab 上方的 38px 把手。展开高度按实际页眉与 Tab 尺寸计算，不再使用 3/4 比例。抽屉白底采用无圆角的直线黑铅上沿，完整遮挡地图背景。提示为「上滑发现更多，下滑隐藏内容」；隐藏档只露滑动把手，内容不可聚焦。顶部把手可拖动或点击，也支持键盘上下箭头。

抽屉内容在展开后独立竖向滚动；内容滚到顶部后下拉可换档，中间档上滑展开、下滑隐藏。横向翻看活动卡不会触发纵向拖动。释放后按手势方向吸附至三个高度，短滑动换一档，长距离拖动可跨过中间档；使用 620ms 的平滑高度动画，拖动时实时跟手。隐藏档点击或上滑可恢复内容。点击活动或建筑进入探索时记录原抽屉档位，再平滑切到默认 1/4 档；连续切换建筑或从详情返回楼层地图不会覆盖原档位。点击「返回」或取消建筑选中时，抽屉带动画恢复进入探索前的档位，地图保留当前视角。复位 / 定位入口保持操作当下的抽屉档位，仅收拢模型并复位地图，同时清除旧的探索记录；切换地图模式保留探索与档位记录，继续查看同一栋建筑。

地图画布完整延伸至 Tab，通过 `CampusScene` 的 `focusInset` 与相机视口偏移，把聚焦中心保持在默认抽屉上方，同时绘制被覆盖的下方地图。换档不改变画布尺寸或相机，隐藏后显示完整地图，不出现蓝色空白。2D 也共用这一抽屉与固定覆盖范围，完整画布延伸到 Tab。320px 宽度仍保持单列，不生成桌面布局。

`npm run test:drawer` 检查三档尺寸、页眉及 Tab 边界、拖动限幅、横向/纵向手势吸附及隐藏档恢复规则。


## 2D 俯视地图规范

2D 直接读取 `assets/maps/campus.json`，与 3D 共用校内/周边建筑、完整道路、水体、绿地、树冠位置、配色和示例定位；运行时无需在线瓦片或额外下载。北向固定朝上，x 向东、z 向南，没有旋转或透视。建筑多面关系的庭院用 even-odd 填色保留空洞，命中测试也排除这些孔洞。校外建筑淡化显示，校界只限制观察中心，不裁出空白边界。

初始中心为 `demoLocation = [175, 135]`；初始倍率为手机宽度 / 720，即约 720m 的横向范围，兼顾理教、图书馆与未名湖周边。倍率限于 0.22–3.2 px/m。投影中心位于顶部控件和默认抽屉之间；换档不缩放或重新生成地图。点击建筑平滑聚焦 720ms，关闭选中保留当前俯视位置；定位按钮平滑复位且保留抽屉档位。减少动画偏好开启时取消聚焦过渡与拖动惯性。

建筑色面采用 `profileFor()` 的屋顶色：现代建筑为亮黄，传统/地标屋顶为薄荷色，边缘带主题黄色墙体轮廓。只描建筑边缘、简化屋脊和设备轮廓，不增加三角网格或厚重投影；选中建筑使用蓝色轮廓。道路白色，草地与圆润树冠明亮浅绿，湖水浅蓝并带少量水纹；周边建筑使用浅纸色。标记和文字使用原 `v-sketch` 与本地小赖字体，优先显示选中建筑、活动建筑、主要地标；放大后补充其他建筑名称，避让搜索/控制器/指北针/提示/比例尺，控制标签密度。

纹理固定在地图坐标中：256×256 的 Canvas 图案重复，纹理块约 77m；宽笔触使用 -30° 的 along/across 坐标，叠色深浅占主导，少量露纸沿同向延伸并渐尖，保留细微纸齿。颜色混入约 2%–35% 暖纸色，持续平涂，没有随机大洞、细线排线或每帧随机上色。轮廓路径只在长边上轻微起伏（上限约 0.18m），圆头圆转折，屏幕上的黑铅宽度基本保持 1px。缩放只改变视图；图案、轮廓与树冠形态不会重新抽样。

Canvas 按设备密度绘制（最高 2 倍），预缓存 Path2D 和色面图案，绘制时剔除可视范围外的要素，只在视图/筛选/选中/尺寸改变或动画进行时更新。单指/鼠标拖动支持短惯性，双指缩放围绕手指中点进行，同时支持中点平移；滚轮以鼠标下的地图点为缩放锚点。方向键平移，加减键缩放。校内建筑可直接点轮廓，也可通过具名 DOM 按钮和原搜索/抽屉选择。

`npm run test:plan` 检查北向投影、坐标互逆、锚点缩放、双指平移缩放、倍率上下限、凹形校界、庭院命中与比例尺；浏览器检查手机布局、点建筑/切换楼层、切换 3D/2D、缩放定位和抽屉恢复。
