## 交互状态

1. 每次进入地图页默认 3D。全景展示真实 OSM 校区轮廓、道路、水面及白灰建筑。
2. 点建筑模型、地图标记、建筑快捷按钮、搜索结果或活动卡片，进入建筑聚焦。相机位置和目标点用三次缓动过渡；楼板同时从紧凑位置向上分开。系统减少动画偏好开启时直接到位。
3. 1F 留在地面；上层楼板和屋顶悬空。所有楼板沿建筑外轮廓生成。聚焦时隐藏周围建筑，保留地形、道路和水面参照，避免背景遮挡楼层。三条矮墙和地板表示一个简易房间。
4. 有活动的房间以浅蓝表示；当前楼层的楼板与边线也用蓝色强调。地图楼层标签显示示例教室号，底部楼层按钮显示活动小点。
5. 直接点楼层/房间模型、浮动楼层标签或底部楼层按钮，同步切换活动列表；列表卡片打开本地详情弹窗。Esc 和关闭按钮返回。
6. 点悬空屋顶、收起楼层或全景按钮，返回校园全景。放大/缩小、单指拖动/鼠标拖动、双指缩放/滚轮均可使用。
7. 示例定位按钮移到理教附近的蓝点，不读取设备位置。
8. 切换 2D 时卸载 3D 场景，保留右上切换器，其余地图内容留白；切回 3D 恢复全景。搜索与分类仍在上方，筛选状态保留。

## 几何与真实信息边界

底图保存于 `assets/maps/`。原始查询矩形包括校外范围，处理脚本使用 OSM 的「北京大学」校界要素，而非把整个查询框当作燕园。建筑按轮廓中心是否位于校界内筛选；道路与凹形校界逐段求交，去掉校外道路。水面和绿地按轮廓中心筛选。校界附近的单个跨界建筑/面要素仍保留原轮廓，并非对每个面做严格布尔裁切。

当前快照保存 226 栋建筑、1639 条校内道路段、12 处水面。未名湖、博雅塔、理科教学楼、百周年纪念讲堂等来自实际 OSM 数据。米制坐标原点为 `[116.304, 39.9915]`，x 向东、z 向南。坐标保留分米精度；不依赖在线瓦片、地图 SDK、字体服务或 CDN。

OSM 有 `height` 时使用该高度；否则按 `building:levels × 3.8m` 推定，没有楼层标注时全景暂按三层。为了演示楼层，理教设四层、讲堂三层、二教五层、一教三层。其余建筑展开最多六个示意层。**这些不代表真实楼层数、室内平面、层高或活动安排。** 内部分隔按轮廓内规则网格生成，不是建筑测绘模型。

楼层间距为 `max(16m, 建筑最大平面尺寸 × 0.42)`，属于展示用分离距离。相机根据平面范围、总分层高度、纵横比和视场角计算容纳整个模型的距离，使用较低的观看角度，减小上层遮挡。用户可继续旋转查看。模型不制作立面窗户、真实结构、精细树木或材质贴图。

## 文件分工与离线启动

- `../MapPage.vue`：搜索、分类、模式切换、底部信息区、详情弹窗、页面状态与专属样式。
- `CampusScene.vue`：Three.js 模型、OrbitControls、射线选取、相机动画、楼层分离及随相机投影的 DOM 标签。标签复用公共手绘纹理，并缓存按钮子树，避免每帧重画彩铅 SVG。
- `demo.js`：演示建筑、楼层、教室和活动；团队改内容优先在此维护。
- `geometry.mjs`：坐标转换、点在多边形内判断、道路线段裁切。
- `scripts/prepare-campus-map.mjs`：从已下载的原始数据生成展示资源。
- `scripts/download-campus-map.mjs`：仅显式刷新数据时访问 Overpass，下载后自动生成展示资源。

在 `design/` 下：

```powershell
npm ci                 # 初次安装依赖需要网络；已有 node_modules 时可跳过
npm run dev            # 地图启动与使用不需要互联网
npm run map:prepare    # 从本地快照重新生成，无网络
npm run test:map       # 校界裁切、投影、资源及活动映射检查
npm run build
npm run preview        # dist 中包含地图、字体和 Three.js
```

仅需要更新底图时执行 `npm run map:download`，此命令需要网络。常规启动与构建绝不运行下载脚本。离线是指依赖已安装后的本地启动，仍通过 Vite 或静态 HTTP 服务提供网页，不是双击 `file://`。

OSM 署名及 ODbL 许可证说明见 `assets/maps/LICENSE.md`。生产构建保留原始地图、转换数据、来源说明和许可证，便于团队分发和追溯。

## 视觉基线

公共字体、按钮和卡片继续遵守 `DESIGN.md`：本地 Xiaolai 圆润手写体、轻微且圆滑的铅笔勾线、饱和黄/浅蓝/薄荷绿/粉色、斜向彩铅平涂的深浅与少量漏色，不整体倾斜。3D 地形使用低饱和绿和蓝，建筑为白灰色。全局透明背景保持；WebGL 地图区域使用浅纸色背景以衬托模型。

地图页通过 `pageMeta.immersive` 压缩公共标题栏并省略占位页脚，保留页眉、页面目录与固定底部 Tab。手机正文可竖向滚动，活动卡横向滑动；320px 宽度仍保持单列，不生成桌面布局。
