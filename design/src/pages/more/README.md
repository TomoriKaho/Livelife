# “我的” · D-07 前端设计

访问 `#/more`。公共页眉与五项 Tab 保留，不再显示开头的“我的”、英文眉题或占位页脚。内容直接从头像、昵称和个人资料开始。页面内部独立纵向滚动，隐藏滚动条，页眉和 Tab 不跟随滚动。

## 首页与交互

1. 个人资料：手绘头像、昵称、校园身份、简介；右上铅笔进入编辑资料。
2. 兴趣小档案：展示已选兴趣，点击“调整”进入选择页。分类直接复用引导页 `onboarding/options.js`，默认选择体育运动、电影放映、社团活动、学术讲座；可全部取消，首页显示空状态。
3. 推荐偏好：黄色彩铅卡片展示当前摘要；提供个性化推荐开关，以及“兴趣优先 / 多些新发现”两种演示状态。关闭个性化推荐时，两张方向卡片禁用。
4. 设置列表：账户与隐私、通知与定位、界面风格、帮助与反馈。

编辑资料中的头像提供三种本地 SVG 示例；“燕园同学”复用智能助手右侧的 `agent/UserPlaneAvatar.vue` 蓝色纸飞机，头像底色使用主题亮黄色彩铅平涂，保留手绘外框，与飞机形成清晰对比。保存后回显到首页，取消不修改原资料。兴趣选择使用独立草稿，保存后才回显。开关与提醒提前时间在当前页面生命周期内立即更新；推荐页与通知页共用活动提醒状态，关闭提醒时禁用提前时间选项。

详情面板在 D-07 内切换，没有新增主页面或 Tab。面板栈记录来源：推荐偏好 → 通知设置 → 返回，会回到推荐偏好；账户 → 修改密码 → 返回，会回到账户。页面切换时归零内容滚动并聚焦标题。浏览器历史管理主路由，面板返回由界面返回按钮管理。

## 视觉与文件分工

- 所有轮廓和彩铅填色使用 `v-sketch`，沿用全局 `sketch.js` 的宽笔触平涂、斜向漏色、轻微圆滑勾线；背景透明，整块组件不倾斜。
- 字体继承小赖字体。昵称 24px，正文设置标题 14–16px，次级说明 11–12px；输入控件 16px，避免手机聚焦时自动放大。
- 黄色为推荐入口与保存按钮的主色；蓝、薄荷、粉、淡紫用于兴趣和设置图标。首页不把所有设置都画成大色块。
- 图标为细线、圆头、自绘 SVG。开关视觉轨道 48×32px，实际按钮 54×44px；减少动态效果时关闭拨动过渡。

## 演示边界与验证

所有数据写死在前端；没有账户、推荐、通知、定位或反馈 API 请求，没有调用系统定位/通知权限，也没有 localStorage 持久化。刷新或离开主页面后恢复默认示例。密码页只比较两次输入、演示成功状态，输入在完成或卸载时清空，不改变真实账号。退出仅跳回已有登录/引导页面。反馈只展示尚未开放的提示，不发送内容。

`npm run build` 验证构建。浏览器检查涵盖资料回显、头像选择、兴趣保存、推荐与通知状态联动、嵌套返回、密码演示、反馈提示、风格入口和退出路径；检查 390px 与 320px 手机宽度，确认固定导航、内容滚动和无横向溢出。
