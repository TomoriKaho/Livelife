# LiLi 智能助手 · 前端设计

访问 `http://127.0.0.1:8765/#/agent`。页面沿用公共小赖字体、`v-sketch` 铅笔轮廓与彩铅平涂；公共页眉和底部 Tab 保留，聊天标题、消息滚动区与固定输入区由本页负责。

## 当前展示

- 固定四条消息：用户问百讲活动、LiLi 推荐百团大战、用户提到苏协掼蛋比赛、LiLi 正在准备回答。`**百团大战**` 显示强调样式。
- 从 `mint / blue / pink / lavender / yellow` 五色池无重复随机选择四种气泡颜色。只在页面创建时分配，编辑、点赞与输入时保持颜色和笔迹稳定。
- LiLi 是原创 SVG Q 版机器人，双手张开打招呼，参考轻盈可爱的迎接动作。头像由 `LiLiAvatar.vue` 管理，消息/输入区图标由 `AgentIcon.vue` 管理。
- 用户消息可以复制、就地编辑、撤回；撤回显示占位文字。助手消息可以复制，赞/踩互斥且再次点击取消；重新生成仅显示后续开放提示，等待回答的操作按钮禁用。
- 加号展开图片/文件选择菜单，多选文件后在输入区显示本地附件与图片缩略图，支持移除。附件不上传，发送按钮不追加消息或请求模型。
- 左侧历史抽屉占手机框架宽度的 2/3，展示几条示例对话；支持遮罩、关闭按钮和 Escape 关闭、焦点约束及背景控件隔离。历史条目不读取真实记录。

当前数据和交互均为页面内原型状态，不持久化。发送、重新生成、历史读取和真实上传等待后续服务接入。页面切换会释放本地图片预览 URL、定时器和事件监听。

## 布局和动效

正文保留可读的字号与行距；较短屏幕仅滚动消息区，输入区位于 Tab 上方。抽屉滑动 380ms，附件菜单轻微上移淡入；思考圆点旋转与省略号交替显示，使用 CSS 动画，支持减少动态效果偏好。

`pageMeta.customHeading` 在 `App.vue` 中省略公共占位标题，`pageMeta.immersive` 省略占位页脚并交由本页管理内容滚动，不影响其他页面的标题和滚动方式。
